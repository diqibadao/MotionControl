# 22-抖动抑制：按 Casiez et al. (CHI 2012) 标准流程调参

> 日期：2026-06-06 | 基准：v0.4.0-milestone | 参考：1€ Filter 论文

## 背景

v0.4.0 静止抖动 15.7px，CMU 目标 <5px，差 3 倍。
1€ Filter 论文的标准调参流程我们没走对 —— fcMin 设高了（1.5），静止时滤波不够。

## 论文标准流程

```
步骤1: β=0, fcMin=1Hz
步骤2: 手静止 → 降 fcMin 直到抖动消失  
步骤3: 手快移 → 升 β 直到滞后可接受
```

## 改动

| 参数 | 旧值 | 新值 | 理由 |
|------|:--:|:--:|------|
| 1€ Filter `fcMin` | 1.5 | **0.8** | 论文步骤2：降 fcMin 压抖动 |

beta=0.05 保留（步骤3已调好）。速度自适应公式 `fc = fcMin + beta × |dx|` 自动处理"静止强滤、移动轻滤"。

## 预期

- 静止抖动: 15.7px → 5-10px
- 总滞后: 202px → ~220px（静止时略增，移动时不变）
- 跟手感: 基本不变（快移时 fc = 0.8+0.05×5.0 ≈ 1.05，接近原来的 1.5）
