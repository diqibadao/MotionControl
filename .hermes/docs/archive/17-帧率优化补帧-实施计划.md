# 光标线性优化 + 帧率补帧 — 实施计划

**目标：** 光标输出稳定 30fps 真实数据 + 60fps 补帧输出，解决线性问题和跳帧感

---

## 问题链

```
摄像头 30fps → frameCount % 2 → 15fps 检测
  → dt 抖动（40~100ms）→ velocity 跳动 → 非线性
  → 67ms 才更新一次光标 → 肉眼可见一跳一跳
```

### 改动 E：新增 60fps 补帧输出

**原理：**
```
真实检测帧（30fps）：   ●────────────────────●
                       33ms
补帧输出（60fps）：     ●─────────○─────────●
                       16.5ms   16.5ms
                       检测帧     补帧
```

**文件：** `MouseController.swift`

新增一个 `startDisplayLink(fps: 60)` / `stopDisplayLink()` 方法，用 `CVDisplayLink` 或 `Timer` 驱动：

```swift
class MouseController {
    private var displayLink: CVDisplayLink?
    /// 当前光标速度（由外部更新）
    var currentVelocity: CGPoint = .zero
    /// 光标平滑位置（由外部更新）
    var currentPosition: CGPoint = .zero
    private let frameDt: TimeInterval = 1.0 / 60.0
    
    func startDisplayLink() {
        CVDisplayLinkCreateWithActiveCGDisplays(&displayLink)
        CVDisplayLinkSetOutputHandler(displayLink!) { [weak self] _, _, _, _, _ -> CVReturn in
            guard let self = self else { return kCVReturnSuccess }
            // 用当前速度持续推光标
            let dx = self.currentVelocity.x * CGFloat(self.frameDt)
            let dy = self.currentVelocity.y * CGFloat(self.frameDt)
            self.currentPosition.x += dx
            self.currentPosition.y += dy
            // CGWarp 移动系统光标
            // ... 复用现有的 moveCursor(to:) 逻辑
            return kCVReturnSuccess
        }
        CVDisplayLinkStart(displayLink!)
    }
    
    func stopDisplayLink() {
        guard let link = displayLink else { return }
        CVDisplayLinkStop(link)
    }
}
```

**文件：** `MotionControlApp.swift`
