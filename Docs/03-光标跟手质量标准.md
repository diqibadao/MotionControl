# 光标跟手质量标准

> 版本：v1.0 | 日期：2026-06-06 | 基准版本：v0.3.0-baseline

## 概述

本文档定义光标跟手质量的量化指标体系。每次修改光标算法后，**必须**运行 `scripts/analyze-cursor-log.sh` 并与此基准对比。

## 指标体系（10 项）

### A. 响应性（权重 40%）

光标对手部移动的响应速度。**值越低越好。**

| # | 指标 | 计算方式 | 基准值 | 目标 |
|:--:|------|------|:--:|:--:|
| A1 | **1€ Filter 延迟** | `|hand - filter| × 屏幕宽 × gain` | 261px | <200px |
| A2 | **T-C 滞后** | `|target - cursor|` 平均值 | 67px | <50px |
| A3 | **总滞后** | A1 + A2 | 328px | <250px |

**解读**：A1 是滤波算法引入的延迟，A2 是 120Hz timer 追赶滞后。总滞后越小越跟手。

### B. 平滑度（权重 35%）

光标移动的流畅程度。**值越低越好。**

| # | 指标 | 计算方式 | 基准值 | 目标 |
|:--:|------|------|:--:|:--:|
| B1 | **Target 步长 avg** | 相邻帧 target 欧氏距离均值 | 64px | 50-80px |
| B2 | **方向反转率** | 连续帧夹角 < -0.7（近乎180°掉头）的次数 | 8 次 | <5 次 |
| B3 | **大跳变 (>200px)** | target 步长 >200px 的帧数 | — | <5 次 |
| B4 | **巨型跳变 (>500px)** | target 步长 >500px 的帧数 | 7 次 | **0 次** |

**解读**：B1 太小=不够灵敏，太大=跳跃。B2 是光标突然反向的次数，反映抖动。B3/B4 是异常跳变，应趋近于零。

### C. 步长分布（权重 10%）

反映光标移动的细腻程度。

| 范围 | 理想占比 | 说明 |
|------|:--:|------|
| 0-50px | 30-50% | 微步，代表精细操作和静止稳定性 |
| 50-100px | 40-60% | 正常移动 |
| 100-150px | 5-15% | 快速移动 |
| >150px | <3% | 极速移动或异常跳变 |

### D. T-C 滞后分布（权重 10%）

反映光标追上目标的速度。

| 范围 | 理想占比 | 说明 |
|------|:--:|------|
| 0-40px | >30% | 光标紧贴目标 |
| 40-80px | 40-50% | 正常滞后 |
| 80-120px | <20% | 明显滞后 |
| >120px | <5% | 严重滞后或异常 |

### E. 覆盖率（权重 5%）

| # | 指标 | 基准值 | 目标 |
|:--:|------|:--:|:--:|
| E1 | X 覆盖率 | 0~1920 (100%) | 100% |
| E2 | Y 覆盖率 | 93~1080 (91%) | 100% |

### F. 检测质量

| # | 指标 | 基准值 | 目标 |
|:--:|------|:--:|:--:|
| F1 | 手部检测率 | — | >80% |

## 综合评分公式

```
评分 = 100
     - (总滞后 - 328) / 10     // 每超基准 10px 扣 1 分，改善则加分
     - 大跳变次数 × 2           // 每次 >200px 扣 2 分
     - 巨型跳变次数 × 5         // 每次 >500px 扣 5 分
     - (反转次数 - 8) × 3       // 每多一次反转扣 3 分

上限 100，下限 0
```

## 使用方式

```bash
# 1. 启动 App 测试
./.build/debug/MotionControl > /tmp/motioncontrol-test.log 2>&1 &

# 2. 测试完成后分析
./scripts/analyze-cursor-log.sh /tmp/motioncontrol-test.log

# 3. 对比基准，确认改善或回退
```

## 红线

- ⛔ 总滞后 >350px（比基准还差）
- ⛔ 巨型跳变 >0 次（chirality bug 必须修）
- ⛔ 方向反转 >15 次（明显抖动）
- ⛔ Y 覆盖率 <90%（边缘够不到）
- ⛔ 评分 <70（多项指标回退）
