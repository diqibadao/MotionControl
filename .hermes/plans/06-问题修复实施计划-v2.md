## 任务清单

### 任务 1：修复手势检测阈值

**文件**：`Detection/GestureAnalyzer.swift`

| 位置 | 现在 | 改为 |
|------|------|------|
| swipe `abs(wristDelta) > 2.0` | 2.0（归一化坐标下永远达不到） | 0.002 |
| tapDropThreshold | 0.001 | 0.0005 |
| tapRiseThreshold | 0.0005 | 0.0003 |
| dualDropThreshold | 0.001 | 0.0005 |
| dualRiseThreshold | 0.0005 | 0.0003 |
| swipeThreshold | 0.003 | 0.001 |

### 任务 2：强制摄像头 640×480 分辨率

**文件**：`Camera/CameraService.swift`

问题：设了 `.vga640x480` 但实际帧尺寸是 1920×1080（导致每帧处理 200 万像素，人脸检测 25 秒）。

方案：遍历 `device.formats`，找到宽 ≤ 640 的格式并设置为 activeFormat。

### 任务 3：人脸轮廓定位替代 yaw/pitch 做注视追踪

**文件**：`Detection/GazeEstimator.swift`、`Detection/DetectionPipeline.swift`

方案：不使用 Vision 的 yaw/pitch（始终为 0/nil），改为用人脸轮廓在画面中的位置：

```
人脸在画面中的归一化位置 = faceContour 的包围盒中心
yawOffset   = (faceCenter.x - 0.5) × 2   →  -1 ~ 1  （左负右正）
pitchOffset = (faceCenter.y - 0.5) × 2   →  -1 ~ 1  （上负下正）
```

用户转头时，人脸在画面上左右移动 → 注视偏移跟着变。
用户低头/抬头时，人脸在画面上上下移动 → 注视偏移跟着变。

**改动**：
- `DetectionPipeline.didOutputFace` — 获取 faceResult.faceContour 的包围盒中心计算偏移
- 传给 GazeEstimator 或直接创建 GazeEstimate
