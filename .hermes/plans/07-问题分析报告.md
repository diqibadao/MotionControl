# MotionControl v0.2 — 问题分析报告

> 2026-05-28

---

## 已确认的事实

### 1. 光标移动 — 终端版正常，.app 包可能不是最新

终端日志 clearly 显示：
```
[mouseMoved] (716.99, 542.81)
[mouseMoved] (681.69, 592.90)
[mouseMoved] (684.33, 671.45)
```

光标在不同位置移动。但用户说没动。可能原因：`.app` 包的二进制不是最新编译的。

### 2. 手势映射 — `defaultMapping()` 已改为全部 noAction

```
SWIPE_UP → noAction
SWIPE_DOWN → noAction
INDEX_TAP → noAction
... 全部 18 个手势都是 noAction
```

配置文件 `config.json` 不存在（已删除），所以首次启动会用默认映射。

### 3. 手势识别 — 持续触发 `swipeUp`

时间序列检测持续识别到 `swipeUp confidence=0.90`。但因为 `isRepeat=true`，重复事件被 `guard !event.isRepeat` 拦截了。第一个非重复事件会查映射表 → `noAction` → 无事发生。

### 4. 防抖 — 生效

`computeCursor` 中距离 < 2 像素不更新光标，指数平滑 0.7/0.3。

---

## 未解决的问题

### P0 — .app 包可能跑的是旧二进制

用户一直在用 `.app` 包打开的程序。虽然我 `cp` 了新二进制，但 macOS 可能缓存了旧版本。

解决方案：确认 .app 包二进制时间戳是最新的。

### P1 — noAction 映射在重复手势下没问题

`isRepeat=true` 的事件被 `guard` 拦截了。非重复事件查 `noAction` → `default: break` → 无副作用。

没有问题。

### P2 — 手势识别过灵敏

`swipeUp` 一直在触发（所有帧都识别为 swipeUp），说明阈值太低或手势太容易触发。但映射是 noAction，所以不影响。

---

## 总结

核心问题只有一个：**用户用 `.app` 包打开的可能不是最新编译的二进制**。代码层面的修改都是正确的。
