# 调研：macOS 中文语音识别方案对比

> 结论：微信语音不可用。推荐三级策略：SpeechAnalyzer(macOS26+) → SFSpeechRecognizer(通用) → Whisper.cpp(离线加强)

---

## 为什么不能直接用微信语音识别

微信 macOS 的"按住说话→转文字"是 WeChat App **内部模块**，属于私有 API，没有对外暴露接口。第三方 App 无法调用。

其他 App 同理：钉钉、飞书的语音识别也是各自内部私有 API。

## 可用方案对比

### 方案对比总表

| 维度 | SFSpeechRecognizer | SpeechAnalyzer (macOS26) | Whisper.cpp |
|------|-------------------|------------------------|-------------|
| **macOS 版本** | 10.15+ | 26+ | 13+ |
| **是否需要网络** | ⚠️ 中文需要（发 Apple） | ❌ 全离线 | ❌ 全离线 |
| **是否需要下载模型** | ❌ 不需要 | ❌ 不需要 | ✅ 首次下载（142MB~3.1GB） |
| **1 分钟限制** | ⚠️ 有（自动重启绕开） | ❌ 无 | ❌ 无 |
| **中文准确率** | ⭐⭐⭐ 日常足够 | ⭐⭐⭐⭐ 好 | ⭐⭐⭐⭐⭐ 很好 |
| **实时中间结果** | ✅ `shouldReportPartialResults` | ✅ 原生支持 | ⚠️ 需要滑动窗口实现 |
| **Apple Silicon 加速** | ✅ 系统自动 | ✅ ANE 原生 | ✅ Metal/ANE |
| **CPU 占用** | 极低 | 极低 | 中（base）/ 高（large） |
| **内存占用** | ~50MB | ~50MB | 500MB~5GB |
| **定制词汇** | ✅ `contextualStrings` | ❌ 无 | ✅ prompt biasing |
| **集成复杂度** | ⭐ 极简（系统框架） | ⭐ 简单（系统框架） | ⭐⭐⭐ 需要打包模型 |
| **App Store 审核** | ✅ 无问题 | ✅ 无问题 | ✅ MIT 协议 + 属性声明 |

### 中文质量详细对比

**SFSpeechRecognizer（zh-CN）：**
- 日常对话（"今天天气怎么样"）→ 准确率 ~95%
- 专业术语（"MediaPipe 关键点"）→ 靠 `contextualStrings` 提高
- 口音 → 标准普通话 OK，方言/口音偏差下降
- 噪音环境 → 会下降
- 注意：zh-CN 需要联网，数据走 Apple 服务器

**Whisper.cpp（large-v3）：**
- 中文评估：WER ~5-8%（取决于模型大小）
- 专业术语好（训练数据覆盖广）
- 口音容错高（多语种训练）
- 噪音环境相对稳定
- 100% 离线，隐私无担忧

### 关于 macOS 26 的 SpeechAnalyzer

2026 年苹果推出的新框架，Dictato 的测试结果是惊喜：
> Apple was a punchline in speech recognition for years. With macOS 26, that has quietly stopped being true.
> Italian result: 4.0% WER — best on-device engine they've tested.

虽然中文没有在同一个测试中，但架构更新说明中文质量也会大幅提升。

## 推荐实施路径

### MVP（现在就用）

```
SFSpeechRecognizer(locale: "zh-CN")
```

- 最简集成，一行代码
- 日常对话够用
- 1 分钟限制 → 闭嘴后自动重启

```swift
// MVP 实现要点
let recognizer = SFSpeechRecognizer(locale: Locale(identifier: "zh-CN"))
let request = SFSpeechAudioBufferRecognitionRequest()
request.shouldReportPartialResults = true
request.contextualStrings = ["MotionControl", "手势控制", "注视追踪"]
```

### 中期升级（macOS 26 普及后）

```
SpeechAnalyzer → SFSpeechRecognizer 降级
```

- 检测 macOS 版本
- >= 26 → 用 SpeechAnalyzer
- < 26 → 保持 SFSpeechRecognizer

### 离线加强（可选，配置页开关）

```
设置页 → "下载离线语音模型"
         → Whisper 模型下载进度
         → 下载完成后 → 优先使用 Whisper
         → 用户可删除模型回到系统方案
```

## 最终建议

| 阶段 | 方案 | 原因 |
|------|------|------|
| MVP | SFSpeechRecognizer | 零依赖，最快上线，日常够用 |
| 上架前 | 检测版本做切换 | macOS 26+ 用 SpeechAnalyzer，低于 26 保持原方案 |
| 后续版本 | 可选 Whisper | 给对隐私/离线有要求的用户一个强化选项 |
