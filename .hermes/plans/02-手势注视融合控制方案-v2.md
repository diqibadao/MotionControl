## 一、架构总览

```
摄像头画面
    │
    ├── FaceMeshDetector         → 头部 yaw/pitch/roll
    │       └── GazeEstimator    → 屏幕区域判定 (3×3)
    │
    ├── HandPoseDetector         → 20个手部关键点
    │       ├── 食指指尖(indexTip)   → 光标精确定位
    │       └── GestureAnalyzer      → 动作手势识别
    │
    └── CursorController (新增)  ← 融合层
            ├── 输入: gazeRegion + fingertipPos
            ├── 输出: cursorScreenPos
            └── 控制: MouseController
```

## 二、光标控制模型

### 2.1 两种模式

| 模式 | 开关 | 定位方式 |
|------|------|---------|
| **头手融合** | 启用注视追踪 = ON | 头选区域(3×3) + 指尖精确定位 |
| **纯手指** | 启用注视追踪 = OFF | 指尖直接映射全屏 |

### 2.2 头手融合模式

**第一层：头部姿态 → 选择屏幕区域（3×3 网格）**

```
yaw（左右转头）：
  < -0.1 rad → 左侧区域
  -0.1 ~ 0.1 → 中间区域
  > 0.1      → 右侧区域

pitch（抬头低头）：
  < -0.1 rad → 上方区域
  -0.1 ~ 0.1 → 中间区域
  > 0.1      → 下方区域
```

**灵敏度参数可调**：即 `gazeSensitivity`，控制阈值大小。灵敏度越高（值越大），阈值越小，微转即可切换区域。

**第二层：食指指尖(indexTip) → 区域内精确定位光标**

```
cursorX = region.x + (indexTip.x - baselineX) × region.width  × fingerSensitivity
cursorY = region.y + (indexTip.y - baselineY) × region.height × fingerSensitivity
```

`fingerSensitivity` 即检测参数面板中的"鼠标速度"滑条。

### 2.3 纯手指模式

```
cursorX = indexTip.x × screenWidth  × fingerSensitivity
cursorY = indexTip.y × screenHeight × fingerSensitivity
```

指尖直接映射全屏，没有区域限制。

### 2.4 区域切换防抖

用户转头选中一个区域后，需要**超出阈值 + 维持 300ms** 才切换区域。防止自然晃动导致区域反复跳变。

防抖参数也跟随 `gazeSensitivity` 联动：灵敏度越低，防抖时间越长。

## 三、摄像头位置自动反推（无需用户标定）

**原理**：系统通过视频画面反推摄像头位置，自动修正头部姿态基线。

### 3.1 推理逻辑

| 摄像头位置 | 人脸在画面中的位置 | 自然头部姿态 |
|-----------|-------------------|-------------|
| 显示器**上方** | 人脸偏**上**且**略微仰头** | pitch baseline 偏大 |
| 显示器**下方** | 人脸偏**下**且**略微低头** | pitch baseline 偏小 |
| 显示器**左侧** | 人脸偏**右**且**面部右侧受光** | yaw baseline 偏正 |
| 显示器**右侧** | 人脸偏**左**且**面部左侧受光** | yaw baseline 偏负 |
| **正对** | 人脸居中 | yaw/pitch 对称 |

### 3.2 自动标定流程

启动后自动执行，无需用户操作：

```
① 前 3 秒收集面部数据帧（每5帧取一次，约30个样本）
② 计算 yaw/pitch 的平均值作为 baseline
③ 排除异常值（突然转头等情况）
④ baseline 确定 → 后续所有 yaw/pitch 都减去 baseline
⑤ 使用过程中持续微调（指数滑动平均）
```

当检测到头部姿态突然大幅变化时（用户重新坐下、调整摄像头），自动重新收集 baseline。

### 3.3 效果

```
用户直视屏幕中心 → yaw≈0, pitch≈0  → 区域 E（中心）
用户向左看        → yaw 偏移较大    → 区域 D/F（左侧）
摄像头在上方时    → 自动减去pitch偏移 → 仍然准确
```

## 四、手势定义（按你说的重新设计）

### 4.1 手势识别方式

所有手势基于**时间序列检测**（不是静态姿势），通过追踪关键点位置随时间的变化来判断手势动作。

| 识别维度 | 用的关键点 |
|---------|-----------|
| 手指位置 | indexTip, middleTip, ringTip, littleTip |
| 手掌位置 | wrist（手腕） |
| 手指相对位置 | 各指尖到wrist的距离、指尖之间的距离 |

### 4.2 预定义手势（你说这样映射）

| 编号 | 你的描述 | 技术检测方式 | 映射动作 |
|------|---------|-------------|---------|
| 1 | **食指单击** | indexTip y 坐标快速下降再回升（单次敲击，持续 < 300ms） | **鼠标左键单击** |
| 2 | **食指双击** | indexTip 两次快速敲击，间隔 < 400ms | **鼠标左键双击** |
| 3 | **食指+中指同时按下** | indexTip 和 middleTip 的 y 坐标**同时**快速下降（双指一起按） | **拖拽开始**（按住左键） |
| 4 | **双指收回（释放）** | 双指同时抬起（indexTip + middleTip y 回升到原始位置） | **拖拽结束**（释放左键） |
| 5 | **手向上挥** | wrist（手掌中心）y 坐标持续下降 + 整只手向上移动（≥ 阈值） | **内容向上滚动**（鼠标滚轮上滑） |
| 6 | **手向下挥** | wrist y 坐标持续上升 + 整只手向下移动 | **内容向下滚动**（鼠标滚轮下滑） |

### 4.3 食指单击（Tap）的检测算法

```
每帧记录 indexTip.y：
┌─────────────────────────────────────┐
│ y  │·····■                           │
│    │·····■·■                         │
│    │·····■·■·■                       │
│    │·····■·■·■·■                     │
│    │■■■■■■■■■■■■■■                   │  ← 手指抬起
│    │         ■ ■ ■ ■ ■               │
│    │             ■ ■ ■ ■ ■           │
│    │                     ■ ■ ■       │
│    └─────────────────────────────► t │
        稳定 → 下降 → 回升 = 一次 tap
```

检测条件：
1. 检查 indexTip.y 在最近 5 帧内下降超过 `tapThreshold`（阈值可配）
2. 随后 3 帧内回升超过 `tapThreshold`
3. 从下降到回升总持续时间 < 300ms
4. 满足 → tap 事件触发

### 4.4 手势优先级（防止误判）

```
双指按下 (index+middle tap) > 食指单击 (index tap) > 上手挥 (swipe up) > 下手挥 (swipe down)
```

双指按下的优先级最高，避免食指单击时被误识别为其他手势。

## 五、检测参数面板改造

### 5.1 当前已有控件

```
手势灵敏度 [■■■■■░░░░░]      ← gestureSensitivity
鼠标速度   [■■■■■■■■░░]      ← mouseSpeed
启用注视追踪 [⚫]             ← gazeFollowEnabled (当前是本地state，需改成生效)
```

### 5.2 改造后

```
手势灵敏度 [■■■■■░░░░░]      ← 手部检测灵敏度（影响手势触发阈值）
鼠标速度   [■■■■■■░░]       ← 手指控制光标的灵敏度（fingerSensitivity）
注视灵敏度 [■■■■■░░░░░]      ← 头部控制区域切换的灵敏度（gazeSensitivity）
启用注视追踪 [⚫]            ← 开关，ON=头手融合 / OFF=纯手指
```

**三个参数的作用域：**

| 参数 | 头手融合模式 | 纯手指模式 |
|------|------------|-----------|
| 鼠标速度 | 指尖在区域内的移动灵敏度 | 指尖在全屏的移动灵敏度 |
| 注视灵敏度 | 头部多少转动才切换区域 | **无效** |
| 手势灵敏度 | 所有手势的触发阈值 | 所有手势的触发阈值 |
