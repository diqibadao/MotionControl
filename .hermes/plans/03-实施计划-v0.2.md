## 每个文件的具体改动

### 1. GazeEstimator.swift
- 增加 `autoCalibrate()` 方法：收集前 3 秒 yaw/pitch 均值作为 baseline
- `estimate()` 返回 `GazeEstimate`: `{ yawOffset, pitchOffset, hasFace }` 替代原 `GazePoint`
- 增加 `gazeSensitivity` 参数接口（后续由 config 传入）

### 2. CursorController.swift（新增）
- 输入：`indexTip: CGPoint`（归一化）、`headOffset: (yaw: Float, pitch: Float)`、`gazeEnabled: Bool`、`mouseSpeed: Float`、`gazeSensitivity: Float`
- 纯手指模式：`cursor = indexTip × screenSize × mouseSpeed`
- 头手融合模式：`cursor = (indexTip + headOffset × gazeSensitivity × 0.2) × screenSize × mouseSpeed`
- 输出：`CGPoint`（屏幕坐标）→ 调用 `MouseController.moveCursor(to:)`

### 3. DetectionParamsView.swift
- 保持"手势灵敏度"滑条
- 保持"鼠标速度"滑条
- 新增"注视灵敏度"滑条（0~1，默认 0.5）
- 保持"启用注视追踪"开关 → 改为绑定到 `GestureConfig.gazeEnabled`

### 4. GestureAnalyzer.swift — 新增时间序列检测

检测算法：

```
每帧记录 indexTip.y、middleTip.y、wrist.y 的滑动窗口（最近 10 帧）:

Tap 检测（食指单击）:
  1. indexTip.y 在 5 帧内下降 > tapThreshold
  2. 随后 3 帧内回升 > tapThreshold
  3. 总持续时间 < 300ms → 触发

Double Tap 检测:
  1. 两次 Tap 间隔 < 400ms → 触发

Dual Tap 检测（双指按下）:
  1. indexTip.y 和 middleTip.y 在 5 帧内同时下降 > tapThreshold → 触发
  2. 双指回升 → 触发 release 事件

Swipe 检测:
  1. wrist.y 在 8 帧内持续上升 > swipeThreshold → 下挥触发
  2. wrist.y 在 8 帧内持续下降 > swipeThreshold → 上挥触发
```

### 5. GestureMappingView.swift — 修复选中修改 + 新UI

**修复点：** 列表中的每行可点击选中 → 选中后下方下拉框自动填充该手势的配置 → 按钮改为"修改"（选中已有）或"添加"（新手势）

**新UI结构：**
```
┌─ 手势映射 ───────────────────────┐
│                                    │
│  List:                             │
│    ☑ 食指单击 → 单击左键           │  ← 点击行选中
│    ○ 食指双击 → 双击左键           │
│    ○ 双指按下 → 拖拽开始           │
│    ○ 双指收回 → 拖拽结束           │
│    ○ 上挥     → 内容上滚           │
│    ○ 下挥     → 内容下滚           │
│                                    │
│  ──── 编辑区（选中后填充）────     │
│  手势: [食指单击    ▼]             │
│  动作: [单击左键    ▼]             │
│  [添加/修改]  [恢复默认]           │
└────────────────────────────────────┘
```

### 6. GestureConfig.swift

新增/修改字段：
```swift
var gazeEnabled: Bool = true
var gazeSensitivity: Float = 0.5

// 新动作类型
enum ActionType: String, CaseIterable {
    case leftClick, doubleClick, rightClick
    case dragStart, dragEnd
    case scrollUp, scrollDown
    case noAction
}

// 新手势类型
enum GestureType: String, CaseIterable {
    case indexTap       // 食指单击
    case indexDoubleTap // 食指双击
    case dualTap        // 双指按下
    case dualRelease    // 双指收回
    case swipeUp        // 上挥
    case swipeDown      // 下挥
}

// 映射结构
struct GestureMapping: Codable {
    let gesture: GestureType
    var action: ActionType
}
```
