# P2+P3 调试：方向控制不激活

## 日志证据

```
hand_detect confidence=0.0     ← 手部检测置信度为 0
finalCursor=(0.005, 0.0)       ← baseCursor 从未移动
```

## 根因

1. **indexPIP 可能为 nil** — 低置信度时 Vision 可能不返回 PIP 关节点，导致 `if let pip = handResult.indexPIP` 失败，走 `resetCursor()`
2. **fingerExtension 阈值太高** — 数值在归一化坐标中很小，`indexExt > 0.15` 可能达不到
3. **confidence=0.0** — 手部检测置信度为 0 意味着关键点质量差

## 修复方案

### 方案 A（推荐）：简化条件，先让方向控制跑起来

1. 去掉 `indexPIP` 的 guard——用 `indexMCP` 或 `indexDIP` 作为 fallback
2. 暂时去掉 fingerExtension 的严格检查（后期再调阈值）
3. 只在 direction length 足够小时 resetCursor

### 方案 B：加日志看 fingerExtension 实际值

先加 print 看 fingerExtension 返回什么值，再调阈值。
