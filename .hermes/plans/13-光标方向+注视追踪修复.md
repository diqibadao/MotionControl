# 光标方向 + 注视追踪修复计划

## 问题列表

### P0 — 光标 X 方向反了

**现状**：去掉 `(1.0 - tip.x)` 后，视频画面正常了，但手指往右光标往左。

**根因**：Vision 框架的前置摄像头输出是**镜像的**。用户右手往右移 → 摄像头画面中手往左移 → tip.x 减小。所以需要 `(1.0 - tip.x)` 补偿这个镜像，让光标方向和手同步。

**修复**：加回 `(1.0 - tip.x)` 镜像翻转。

```
screenX = (1.0 - tip.x) * screen.width * CGFloat(config.mouseSensitivity)
```

改文件：`Sources/MotionControl/App/MotionControlApp.swift`

### P1 — 注视追踪不生效

**现状**：日志显示 `yaw=0.0 pitch=nil`，注视偏移始终为 0。

**根因分析**：
1. `GazeEstimator` 中 pitch 返回 nil（Vision 框架的头部姿态估计在某些硬件上可能不支持 pitch）
2. `CursorController.updateGazeOffset` 中 `gazeActive = true` 被无条件设置（即使 `hasFace=false` 也设 true）

**修复**：
1. 修复 `updateGazeOffset`：只有 `hasFace=true` 时才设 `gazeActive = true`
2. 检查 GazeEstimator 为什么 pitch 为 nil（可能需要不同的 Vision 请求配置）

改文件：
- `Sources/MotionControl/Control/CursorController.swift` — 修复 gazeActive 逻辑
- `Sources/MotionControl/Detection/GazeEstimator.swift` — 检查 pitch 问题

## 改动清单

| # | 文件 | 改动 | 类型 |
|---|------|------|------|
| 1 | MotionControlApp.swift | screenX 加回 `(1.0 - tip.x)` | P-PARAM |
| 2 | CursorController.swift | updateGazeOffset 只有 hasFace 时设 gazeActive | P-LOGIC |
| 3 | GazeEstimator.swift | 分析 pitch=nil 根因 | P-LOGIC |

## 验证方式

1. 编译通过 → 启动 → 伸右手往右移 → 光标往右跟
2. 注视追踪打开 → 人脸偏转 → 光标有偏移
