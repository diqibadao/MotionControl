# 食指指向 + 注视融合光标控制方案（基于行业调研）

## 问题现状

1. **光标颤动** — Vision 手部关键点有高频噪声，直接映射屏幕坐标导致抖动
2. **五指识别** — 只要 indexTip 被检测到就移动光标，全伸/握拳都触发
3. **注视追踪** — yaw/pitch 始终为 0，未生效
4. **光标方向** — 需要 `(1.0 - tip.x)` 补偿前置摄像头镜像

## 方案：食指方向 → 速度映射（Joystick 模式）

### 原理

从**绝对定位**改为**方向性控制**。用食指指向的方向控制光标移动的方向和速度，类似于游戏摇杆。

### 参考依据

| 来源 | 关键结论 |
|------|---------|
| **MediaPipe Pointing Gesture** | 用 `normalize(indexTip - indexMCP)` 构造方向向量，映射到光标速度 |
| **ControlAir / ManualEyes** | 速度 = Gain × 方向向量 × 非线性曲线(二次方/四次方)，低速区更精细 |
| **Leap Motion / Dragonfly** | 注视定概率区域 + 手指精调，超出时降级到纯手控 |

## 核心实现细节

### 1. 食指方向向量

```swift
// 使用 indexPIP 替代 indexMCP 更稳定（MCP 可能被手掌运动干扰）
let dx = indexTip.x - indexPIP.x
let dy = indexPIP.y - indexTip.y  // Vision y 向上，翻转
let length = sqrt(dx*dx + dy*dy)
let deadZone: CGFloat = 0.02      // 死区，消除静止时的微颤
guard length > deadZone else { stop() }
let normalized = CGPoint(x: dx/length, y: dy/length)
let speed = pow((length - deadZone)/(maxExtension - deadZone), 2.0)  // 二次方曲线
velocity = CGPoint(x: normalized.x * speed * sensitivity,
                    y: normalized.y * speed * sensitivity)
```

### 2. 滤波方案：One Euro Filter（行业标准）

比指数平滑更智能的自适应低通滤波器：

```swift
// One Euro Filter 核心
let cutoff = minCutoff + speedCoef * abs(velocity)  // 速度越快截止频率越高
let alpha = 1.0 / (1.0 + dt * cutoff)               // 自适应平滑系数
filtered = alpha * filtered + (1 - alpha) * raw
```

- 低速（手指微动）→ 低截止频率 → 强滤波去抖
- 高速（手指大幅移动）→ 高截止频率 → 低延迟跟随

### 3. 手指伸展检测

```swift
let extensions = hand.fingerExtension()
// 只有食指伸展 + 其他手指卷曲（指尖在 PIP 后方）
let indexExtended = extensions[.index] > indexThreshold
let othersCurled = extensions[.middle] < middleThreshold
                 && extensions[.ring] < ringThreshold
                 && extensions[.little] < littleThreshold
// 五指全伸 → 离合器模式，断开光标控制
let allExtended = extensions.values.allSatisfy { $0 > openHandThreshold }
```

### 4. 注视融合（加法融合）

```
gazeYaw/Pitch → 屏幕偏移 → 粗粒度区域锚点
手指方向 → 速度 → 细粒度控制
光标位置 = gazeAnchor + ∫(fingerVelocity) dt
```

## 验证

1. 食指指向右 → 光标匀速右移
2. 食指轻度伸出 → 光标缓慢移动（二次方曲线）
3. 卷曲食指 → 光标停
4. 五指全伸 → 光标停（离合器）
5. 加上注视 → 转头改变移动区域
