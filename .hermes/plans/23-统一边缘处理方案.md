# 23-统一边缘处理方案：可变绝对映射 + 帧丢失保护

> 日期：2026-06-06 | 参考：US Patent US20150177855A1 + US20020033799A1 + UmeTrack (Meta, SIGGRAPH 2022)

## 行业方案

### 可变绝对映射（Variable Absolute Mapping）

专利方案将手部工作空间划分为**三区**：

```
         Interior          Border         Margin
    ┌──────────────┬──────────────────┬────────────┐
    │              │                  │            │
    │  gain=base   │  gain 渐变 boost  │  saturation│
    │  (精细控制)   │  (触达全屏)       │  (贴边)    │
    │              │                  │            │
    └──────────────┴──────────────────┴────────────┘
   origin        dist=0.12        dist=0.25     摄像头边缘
```

| 区 | 手离原点距离 | 增益 | 行为 |
|------|:--:|:--:|------|
| Interior | < 0.12 | ×1.0 | 精细控制，跟手感不变 |
| Border | 0.12~0.25 | ×1.0→×2.0 线性 | 手近摄像头边缘 = 光标近屏幕边缘 |
| Margin | > 0.25 | 饱和 | 光标贴边，不跳 |

**关键**：α-blending 平滑过渡，border 区用 `lerp(gain, boostedGain, alpha)` 防止增益突变。

### 帧丢失保护（Temporal Gap Guard）

UmeTrack (Meta) 方案：当检测到帧间隔异常（>200ms），用上一帧的 target + 预测速度做平滑过渡，而非直接跳到新位置。

## 统一方案设计

### 改动 1：三区可变增益

```swift
// CursorController.updateWithAbsolutePosition()

let dist = sqrt(offsetX*offsetX + offsetY*offsetY)

let gainMultiplier: CGFloat
if dist < 0.12 {
    gainMultiplier = 1.0                    // Interior: 跟手不变
} else if dist < 0.25 {
    let t = (dist - 0.12) / 0.13           // Border: 1.0→2.0 线性
    gainMultiplier = 1.0 + t * 1.0
} else {
    gainMultiplier = 2.0                    // Margin: 饱和贴边
}
```

vs 现在的固定 gain=2.0：
- 死区从 13%→6.5%（border 区增益更高，手不用走那么远）
- 中心精控不变（dist<0.12 时 gain 跟现在一样）
- 边缘自然触达（border 区增益自动升高）

### 改动 2：帧丢失平滑

```swift
// MotionControlApp.onHandResult 中
let now = ProcessInfo.processInfo.systemUptime
let dt = now - lastFrameTime
if dt > 0.2 && lastTarget != nil {
    // 帧丢失 >200ms: 不跳，用预测位置
    let predictedX = lastTarget.x + velocityX * CGFloat(dt)
    let predictedY = lastTarget.y + velocityY * CGFloat(dt)
    // 用预测值平滑过渡到新 target
}
lastFrameTime = now
```
