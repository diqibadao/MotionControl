# 光标加速算法重构 — 事件链文档

> 来源：用户反馈光标移动不够远、不够平滑
> 根因：调研确认增益方向反了 + 无速度基计算 + 硬死区

---

## 事件列表

| 编号 | 事件名 | 触发源 | 触发时机 | 前置条件 |
|------|-------|--------|---------|---------|

| E2 | **光标位置更新** | `updateWithDelta` 被调用 | 每帧手指位移计算后 | 位移超过死区阈值 |

## 每个事件的完整处理链路

### E1：手指位移计算

#### 1. 当前算法（有问题）

```swift
// CursorController.updateWithDelta
let dx = (lastTip.x - tip.x) * screenSize.width * CGFloat(sensitivity)  // = 24
let dy = (tip.y - lastTip.y) * screenSize.height * CGFloat(sensitivity)

// 死区：小于 5px 忽略
guard abs(dx) > 5 || abs(dy) > 5 else { return }

let dist = sqrt(dx*dx + dy*dy)
let factor: CGFloat = dist < 30 ? 1 : (dist < 200 ? 3 : 6)  // ← 增益方向反了！
```

**问题：**
- 位移越大 factor 越大 → 增益越小 → 快速移动反而最慢
- 5px 硬死区丢弃小位移，不平滑
- 没有除以时间，帧率抖动直接影响光标

#### 2. 目标算法（libinput adaptive 模型）

```swift
// 速度基的加速曲线
// 1. 计算速度（位移 ÷ 时间）
// 2. 速度慢 → 低增益（精细控制）
// 3. 速度快 → 高增益（快速跨屏）

func accelerationFactor(velocity: CGFloat) -> CGFloat {
    if velocity < 50 { return 0.4 }           // 极慢 → 精细 ×0.4
    if velocity < 200 { return 1.0 }          // 正常 → 1:1
    // 快速→加速，最高 4x
    let factor = 1.0 + (velocity - 200) / 800.0 * 3.0
    return min(factor, 4.0)
}

let velocity = sqrt(dx*dx + dy*dy) / max(dt, 0.001)
let factor = accelerationFactor(velocity: velocity)
// (dt 是帧间时间，由 onHandResult 的 frameDt 参数提供)
```

#### 3. 测试场景清单

| ID | 类型 | 输入 | 预期 | Mock | Teardown |
|----|------|------|------|------|---------|
| E1-T1 | 正向 | 手指慢速移动（velocity < 50） | 增益 0.4x，精细控制 | 固定速度值 | 无 |
| E1-T2 | 正向 | 手指中速移动（velocity 50-200） | 增益 1x，1:1 映射 | 固定速度值 | 无 |
| E1-T3 | 正向 | 手指快速移动（velocity > 200） | 增益 1x-4x，快速跨屏 | 固定速度值 | 无 |
| E1-T4 | 异常 | 手指检测丢帧（dt 突变） | 不跳变，平稳过渡 | 模拟大 dt | 无 |
| E1-T5 | 边界 | 手指极慢微动（velocity < 10） | 光标微动，不卡死 | 固定速度值 | 无 |

## 状态机

```
updateWithDelta 被调用
  │
  ├─ guard abs(dx) > 5 || abs(dy) > 5  → 死区忽略（保留，但降低阈值）
  │
  ├─ velocity = dist / dt
  │
  ├─ velocity < 50 → factor = 0.4（÷0.4 = ×2.5，精细减速）
  ├─ velocity < 200 → factor = 1.0（1:1）
  └─ velocity >= 200 → factor = 1.0~4.0（加速）
      │
      ▼
  currentPosition += delta * factor
      │
      ▼
  clamp 到屏幕边界
```
