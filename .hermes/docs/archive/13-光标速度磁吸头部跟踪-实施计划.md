### Task 1: 改为 Delta 灵敏度（CursorController）

**Objective:** 将当前位置映射改为位移（delta）映射，使灵敏度控制"手移 1cm = 光标移 N cm"的比例。

**Files:**
- Modify: `Sources/MotionControl/Control/CursorController.swift`

**改动说明:**

当前 `updateTargetPosition` 接收的是绝对目标位置（target），用 EMA 追过去。

改为：**不再计算 target**，而是在 `CursorController` 内部直接做 delta 计算：

```swift
/// 更新光标位置（基于指尖位移）
/// - Parameters:
///   - tip: 当前帧指尖归一化坐标 (0~1)
///   - lastTip: 上一帧指尖归一化坐标
///   - screenSize: 屏幕尺寸
///   - sensitivity: 灵敏度倍率
func updateWithDelta(tip: CGPoint, lastTip: CGPoint, screenSize: CGSize, sensitivity: Float) {
    let dx = (tip.x - lastTip.x) * screenSize.width * CGFloat(sensitivity)
    let dy = (tip.y - lastTip.y) * screenSize.height * CGFloat(sensitivity)
    
    // 自适应平滑：大位移（快速跨越）→ 阻尼大一些防抖
    let dist = sqrt(dx*dx + dy*dy)
    let factor: CGFloat = dist > 100 ? 3 : 6  // 比原来激进一点
    currentPosition.x += dx / factor
    currentPosition.y += dy / factor
    
    // 剪辑到屏幕范围
    currentPosition.x = max(0, min(currentPosition.x, screenSize.width))
    currentPosition.y = max(0, min(currentPosition.y, screenSize.height))
    
    fingerActive = true
}
```

**注意：`updateTargetPosition` 保留不变**（继续用于测试和外部调用），新增 `updateWithDelta` 方法。`computeCursor` 不需要改。

### Task 3: 底部 Dock 图标磁吸

**Objective:** 让光标能磁吸到 macOS 底部 Dock 的应用图标。

**Files:**
- Modify: `Sources/MotionControl/Control/UIElementScanner.swift`
- Modify: `Sources/MotionControl/Control/CursorController.swift`（如果磁吸逻辑需要适配 Dock 元素）

**改动说明:**

在 `UIElementScanner` 中新增 `scanDock()` 方法，在 `scan()` 中追加调用。

Dock 的 AX 结构：
```
AXApplication "Dock" (PID from NSWorkspace)
  └── kAXWindowsAttribute → 窗口列表
       └── kAXChildrenAttribute → 子元素
            └── role="AXDockItem" → Dock 图标（有 title、frame）
```

```swift
/// 扫描 Dock 图标
private func scanDock() {
    guard let dockApp = NSWorkspace.shared.runningApplications.first(where: {
        $0.bundleIdentifier == "com.apple.dock"
    }) else { return }
    
    let dockElement = AXUIElementCreateApplication(dockApp.processIdentifier)
    
    // Dock 的容器元素通常是第一个窗口的子元素
    guard let windowsRef = getAttributeValue(dockElement, kAXWindowsAttribute as String) else { return }
    let windows = axElements(from: windowsRef)
    
    for window in windows {
        guard let childrenRef = getAttributeValue(window, kAXChildrenAttribute as String) else { continue }
        let children = axElements(from: childrenRef)
        for child in children {
            guard let role = getAttributeValue(child, kAXRoleAttribute as String) as? String,
                  role == "AXDockItem" || role == "AXButton" else { continue }
            if let info = extractElementInfo(child) {
                newElements.append(info)
            }
        }
    }
}
```

将 `scanDock()` 在 `scan()` 方法末尾调用（在扫描完前台窗口后追加）。
