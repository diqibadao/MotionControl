# 光标映射核心概念

## 一次讲清：手怎么变成光标

你的手在摄像头前，摄像头拍到归一化坐标 `(x, y)`，x 和 y 都在 0~1 之间。

### 1. offset — 手离原点有多远

```
原点 = (0.5, 0.4)  ← 固定，手在此=光标在屏幕中心
offset = 手位置 − 原点

手在 0.6 → offset = 0.6 − 0.5 = 0.1
手在 0.3 → offset = 0.3 − 0.5 = −0.2
```

offset 是零基础量，怎么映射到屏幕都靠后面两个参数。

### 2. gain — 放大倍数

```
gain = 2.0

手移 1cm → 光标移 2cm
手移 5cm → 光标移 10cm
```

gain 越大越灵敏，越小越精控。屏幕边缘 gain 自动提到 1.3 倍帮你触达。

### 3. cursorX — 光标位置

```
屏幕 1920×1080，中心 = (960, 540)
cursorX = 960 − offset × 1920 × gain

手在 0.6 → offset=0.1 → 960 − 0.1×1920×2.0 = 576
手在 0.75 → offset=0.25 → 960 − 0.25×1920×2.6 = 960−1248 = −288 ❌ 负的！
```

负值说明 offset 太大了，gain 把偏移放大到超出屏幕。

### 4. offset 上限 — 防负值

```
offset 上限 = 屏幕中心 ÷ (屏幕宽 × gain) = 0.5 ÷ gain

gain = 2.0 → 上限 = 0.25 → cursorX 永不离 [0, 1920]
gain = 2.6 → 上限 = 0.192 → cursorX 永不离 [0, 1920]
```

offset 到了上限就截断，cursorX 永远等于屏幕边缘，不会飞出去。手一回来，offset 立刻低于上限，光标直接跟。

### 5. clamp — 最后的门卫

```
clamp(x, 0, 1920) = 掐头去尾
负值 → 0，超大值 → 1920，正常值 → 不变
```

offset 上限生效后，cursorX 不会出界，clamp 还在但不需要了。

---

## 为什么 offset 上限是正解

```
旧方案：offset 无上限 → cursorX 飞负 → clamp 救场 → 手往回走要从负值区走出来 → 死

新方案：offset 有上限 → cursorX 永不离 [0, 屏幕宽] → 手回立刻跟 → 零死区
```

**堵源头，不堵出口。**
