# MotionControl 需求文档

> 版本：v1.0
> 更新：2026-05-27
> 状态：需求确认中

---

## 1. 产品概述

### 1.1 一句话介绍
通过普通摄像头实现"手势控制 + 眼睛注视 + 语音输入"三合一的免触控 macOS 控制系统。

### 1.2 解决什么问题
- 手没空操作电脑时（吃东西、画图、演示）
- 身体不方便使用键盘鼠标时
- 想要更自然的人机交互方式

### 1.3 核心价值
> 眼睛看哪里，光标定位到哪里；手动一动，点击/确认/滚动；张嘴说话，文字直接输入。

## 2. 用户画像

**目标用户：**
- 设计师 / 视频剪辑师（双手忙不过来）
- 演讲者 / 直播主（边讲边操作电脑）
- 残障人士或暂时性手部不便
- 极客 / 技术爱好者

**使用场景：**
- 读网页时，眼睛看链接，手势捏合打开
- 视频编辑时，挥手滚动时间轴
- 打字时，张嘴语音输入，闭嘴提交

## 3. 用户体验原则

1. **低延迟** — 手势/注视/语音的响应延迟 < 200ms
2. **高容错** — 误操作有防抖/冷却机制，不轻易触发
3. **零干扰** — 不遮挡正常操作，随时可关闭
4. **可配置** — 每个手势映射、每个阈值都可改
5. **隐私优先** — 摄像头数据本地处理，不上云端

## 4. 功能详情

### 4.1 手势识别控制（P0）

#### 4.1.1 检测能力
- 单手 21 个关键点实时追踪（Vision VNDetectHumanHandPoseRequest）
- 帧率：目标 30fps，最低 15fps
- 最大检测距离：摄像头画面内手部完整可见

#### 4.1.2 手势类型

| 手势 | 动作 | 默认映射 | 说明 |
|------|------|----------|------|
| **张开（OPEN）** | 五指自然张开 | 鼠标移动（无按键） | 默认状态，自由移动光标 |
| **单指（POINT）** | 只伸食指，其他握拳 | 鼠标移动 + 轻按点击 | 类似触碰屏，指哪点哪 |
| **捏合（GRAB）** | 拇指+食指捏合（< 阈值） | 左键点击 | 确认、选择 |
| **两指捏（PINCH）** | 拇指+中指捏合（食指伸直） | 右键点击 | 上下文菜单 |
| **快速双捏（DBL_PINCH）** | 500ms 内两次捏合 | 双击 | 打开文件/应用 |
| **剪刀手（PEACE）** | 食指+中指伸直 V 字 | 滚动模式 | 垂直移动 → 页面滚动 |
| **握拳（FIST）** | 全手指弯曲握拳 | 回车确认 | 确认对话框/发送消息 |
| **挥手（SWIPE）** | 手部水平快速扫过 | 后退/前进 | 浏览器返回/应用切换 |

#### 4.1.3 判定规则
- **捏合检测**：拇指尖 (landmark 4) 与食指尖 (landmark 8) 的欧氏距离 < pinchThreshold（默认 40px）
- **两指捏**：拇指尖 (landmark 4) 与中指尖 (landmark 12) 距离 < pinchThreshold，同时指尖 (landmark 8) 与掌根 (landmark 0) 距离 > 伸展阈值
- **双击判定**：两次捏合事件间隔 < 500ms
- **冷却时间**：同一种手势触发后 200ms 内不重复触发

#### 4.1.4 坐标映射
- 摄像头画面（640×480）→ 屏幕坐标（根据屏幕分辨率缩放）
- 支持灵敏度系数（0.5~2.0）
- 支持指数平滑：`pos = pos * (1 - α) + newPos * α`，α 默认 0.4

### 4.2 眼睛注视定位（P1）

#### 4.2.1 检测方式
使用 Vision Framework 的 `VNDetectFaceLandmarksRequest` 提取：
- 眼睑轮廓关键点（左右眼各 6 个轮廓点）
- 头部姿态欧拉角（roll, pitch, yaw）
- 瞳孔位置（从眼睑轮廓推算）

#### 4.2.2 注视点计算
1. 提取眼睑轮廓 → 推算虹膜/瞳孔位置
2. 结合头部姿态（yaw = 水平转动，pitch = 垂直转动）
3. 映射到屏幕坐标：
   - yaw → 屏幕水平位置（左/右）
   - pitch → 屏幕垂直位置（上/下）
   - 虹膜偏移 → 屏幕内微调
4. 指数平滑滤波防抖动

#### 4.2.3 精度说明
- **无 TrueDepth 摄像头时**：注视点定位精度约为屏幕 1/6 区域级别
- **足够用于**：定位输入框、锁定目标元素
- **不够用于**：像素级鼠标定位（仍用手势做精确控制）
- **注视→手势协同**：手势做精确点击，注视做区域定位

### 4.3 嘴型检测 + 语音输入（P1）

#### 4.3.1 嘴型检测
从 `VNDetectFaceLandmarksRequest` 提取嘴部关键点：
- 上唇中点 (landmark outer: 上唇上缘中点)
- 下唇中点 (landmark outer: 下唇下缘中点)
- 嘴左角 / 嘴右角

**张嘴判定** = 上唇-下唇距离 > mouthOpenThreshold（归一化比 0.6）
**闭嘴判定** = 上唇-下唇距离 < mouthCloseThreshold（归一化比 0.4）

使用**滞回区间**防治抖振：open 阈值 > close 阈值

#### 4.3.2 语音识别
- 框架：`SFSpeechRecognizer`（macOS 10.15+）
- 语言：zh-CN（中文普通话）
- 模式：`SFSpeechRecognitionTaskHint.dictation`（听写模式）
- 配置：`shouldReportPartialResults = true`（实时输出）
- 请求权限：`SFSpeechRecognizer.requestAuthorization()`

#### 4.3.3 语音输入流程

```
用户张嘴 → 嘴型检测 OPEN → 等待 debounce(300ms) → 
  ├─ 注视点在输入框 → 自动聚焦 + 启动语音识别
  ├─ 无注视点       → 启动语音识别（光标位置输入）
  └─ 延迟 2s 无语音 → 自动停止

识别中 → 实时显示识别文字 → 用户闭嘴 →
  ├─ 嘴型检测 CLOSED → 停止语音识别
  ├─ 等待最终结果
  └─ 文字自动输入到当前聚焦应用
```

#### 4.3.4 异常处理
| 情况 | 表现 |
|------|------|
| 无麦克风权限 | 弹窗提示，引导系统偏好设置 |
| 无网络（SFSpeechRecognizer 需要网络） | 文字提示"语音识别需要网络连接" |
| 无法识别语音 | 检测到张嘴但 3s 无识别结果 → 自动停止 |
| 嘴型频繁切换 | 使用滞回 + 300ms debounce |
| 同时手势操作 | 语音输入优先，手势在语音期间降低灵敏度 |

### 4.4 整体交互逻辑

#### 4.4.1 工作模式

**模式一：注视+手势协同（推荐）**
1. 眼睛看向屏幕 → 注视光标跟随
2. 看到目标元素（链接/按钮/输入框）→ 该元素被高亮
3. 手势捏合 → 点击该元素
4. 张嘴 → 语音输入到注视到的输入框

**模式二：纯手势（传统）**
1. 手势控制鼠标移动
2. 手势捏合点击
3. 手势控制滚动/拖拽
4. 闭嘴触发语音输入

#### 4.4.2 状态切换逻辑
| 输入 | 输出 | 优先级 |
|------|------|--------|
| 仅手势移动 | 鼠标移动 | 中 |
| 手势捏合 | 点击动作 | 高 |
| 注视锁定元素 + 手势点击 | 在注视元素上点击 | 最高 |
| 张嘴 | 启动语音 | 高（打断手势） |
| 闭嘴 + 语音中 | 停止语音 + 提交文字 | 高 |

## 5. 配置系统

### 5.1 设计原则
1. **手势即命令** — 每个手势可以映射到任意操作（鼠标 / 键盘 / 系统 / 自定义快捷键）
2. **两级配置** — 默认映射开箱即用 + 用户可深度自定义
3. **可视化编辑** — 配置面板中直接编辑，所见即所得
4. **即时生效** — 修改配置后无需重启，检测线程热加载
5. **多配置方案** — 支持保存/切换多个配置方案（如「日常」/「演示」/「剪辑」）

### 5.2 默认手势映射表（Mac 鼠标 + 触控板）

| 手势 | 默认映射 | 类别 | 对应 Mac 原生操作 |
|------|---------|------|-----------------|
| **张开五指（OPEN）** | 鼠标移动（无按键） | 鼠标 | — |
| **单指点（POINT）** | 鼠标移动 + 轻按一次 | 鼠标 | 光标悬浮 + 触控板轻点 |
| **捏合拇指+食指（GRAB）** | 左键点击 | 鼠标 | 单指触控板点击 |
| **捏合拇指+中指（PINCH）** | 右键点击 | 鼠标 | 双指触控板点击 |
| **快速两次捏合（DBL_PINCH）** | 双击 | 鼠标 | 文件/应用打开 |
| **剪刀手 V（PEACE）** | 进入滚动模式 | 滚动 | 双指上下滑动 |
| **握拳（FIST）** | 回车（Enter） | 键盘 | 确认表单/发送 |
| **挥手向左（SWIPE_LEFT）** | 切换上一个桌面 | 系统 | 三指左滑 |
| **挥手向右（SWIPE_RIGHT）** | 切换下一个桌面 | 系统 | 三指右滑 |
| **挥手向上（SWIPE_UP）** | Mission Control | 系统 | 三指上滑 |
| **挥手向下（SWIPE_DOWN）** | App Exposé | 系统 | 三指下滑 |
| **五指张开推掌（OPEN_PALM）** | 显示桌面 | 系统 | 五指张开 |
| **五指捏合（FIVE_PINCH）** | Launchpad | 系统 | 五指捏合 |
| **单指拖拽（DRAG）** | 拖拽模式（按住左键移动） | 鼠标 | 三指拖拽 |
| **竖大拇指（THUMBS_UP）** | 空格预览（Quick Look） | 系统 | 空格键 |

### 5.5 配置持久化
- 格式：JSON（可读、可导出、可手动编辑）
- 路径：`~/Library/Application Support/com.motioncontrol/config.json`
- 多方案：支持保存多套配置方案，快速切换
  - 默认方案「日常使用」不可删除
  - 用户可创建「演示模式」「视频剪辑」「游戏」等方案
- 导入/导出：支持 JSON 文件导入/导出，方便分享

### 5.7 配置变更热加载
- 用户保存配置后 → 写入 JSON 文件
- 检测线程的 `GestureAnalyzer`、`GazeEstimator` 等模块监听配置文件变化
- 使用 `DispatchSource.FileSystemObject` 或 `FileMonitor` 实现
- 配置变化 → 原子性更新（先写临时文件再 rename，避免读到不完整配置）

## 6. 权限要求

| 权限 | 用途 | API | macOS 版本 |
|------|------|-----|-----------|
| 摄像头 | 手势/人脸/注视检测 | AVCaptureDevice | 10.14+ |
| 麦克风 | 语音输入 | SFSpeechRecognizer | 10.15+ |
| 辅助功能 | 模拟鼠标/键盘输入 | CGEvent | 10.11+ |
| 语音识别 | 语音转文字 | SFSpeechRecognizer | 10.15+ |

### 6.1 权限申请顺序
1. 首次启动 → 引导页 → 依次请求摄像头 → 麦克风 → 语音识别
2. 辅助功能权限（需用户在系统偏好设置中手动授权）
3. 权限不足时，功能降级运行（仅手势可用，无语音/注视）

## 7. 非功能性需求

### 7.1 性能
- CPU 占用：目标 < 20%（Apple Silicon），Intel 上 < 40%
- 内存占用：< 200MB
- 帧率：检测循环 ≥ 15fps，渲染循环 ≥ 30fps
- 启动时间：< 5s（模型预热）

### 7.2 隐私
- 所有摄像头数据本地处理，不上传
- 语音识别使用系统 SFSpeechRecognizer（部分场景需网络，但数据走 Apple 服务）
- 不得采集用户操作数据
- App Store 隐私标签如实填写

### 7.3 兼容性
- macOS 14.0+（Sequoia）
- Apple Silicon 优先优化
- 支持 Intel Mac（性能降级）
- 多显示器：主屏幕或用户选择屏幕
