# 数据资产规划 — 光标算法训练数据集

> 日期：2026-06-06 | 状态：数据采集阶段

## 目标

积累版本测试数据，未来用于：
- **离线回放测试**：新算法直接在历史手部数据上跑，秒出 23 项指标，不用真人测
- **参数自动调优**：用历史数据做贝叶斯优化/强化学习，自动搜索最优参数
- **模型训练**：手部位置序列 → 理想光标轨迹的端到端模型

## 数据资产清单

| 资产 | 格式 | 位置 | 用途 |
|------|------|------|------|
| 原始日志 | 文本 | `Docs/logs/vX.Y.Z.log` | 完整检测帧数据 |
| 23项指标 | 表格 | `Docs/04-指标历史记录.md` | 版本评分标签 |
| 光标轨迹 | TSV | `Docs/logs/vX.Y.Z-trace.tsv` | 训练用特征 |
| 元数据 | YAML | `Docs/logs/vX.Y.Z-meta.yaml` | 版本参数配置 |

## 日志数据字段

原始日志 `CURSOR-ABS` 行包含：

```
hand=(hx,hy) filter=(fx,fy) target=(tx,ty) cursor=(cx,cy)
```

| 字段 | 含义 | 训练用途 |
|------|------|------|
| handX, handY | palmCenter 原始归一化坐标 | 输入特征 |
| filterX, filterY | 1€ Filter 输出 | 滤波效果标签 |
| targetX, targetY | 映射后的屏幕坐标 | 算法输出 |
| cursorX, cursorY | 120Hz lerp 后的实际光标 | 最终轨迹 |

