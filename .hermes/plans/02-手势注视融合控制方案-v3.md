# MotionControl — 头手融合光标控制 + 手势动作映射方案 v3

> 状态：设计稿（待评审）
> 版本：v3

## 一、整体架构

```
摄像头画面
    │
    ├── FaceMeshDetector      → yaw / pitch
    │       └── GazeEstimator → 头部偏移方向 (上/下/左/右)
    │
    ├── HandPoseDetector      → 20个手部关键点
    │       ├── indexTip         → 光标基础定位
    │       └── GestureAnalyzer → 手势识别
    │
    └── CursorController (新增)
            ├── 输入: headOffset + fingertipPos（归一化坐标）
            ├── 融合: fingertip + headOffset × gazeSensitivity
            └── 输出: cursorScreenPos → MouseController
```

## 二、光标定位：头手融合模型

### 2.1 两种模式

| 模式 | 条件 | 定位方式 |
|------|------|---------|
| **头手融合** | `gazeEnabled = ON` | **指尖定位 × 头部偏移修正** |
| **纯手指** | `gazeEnabled = OFF` | 指尖直接映射全屏 |

### 2.2 纯手指模式

```
cursorX = indexTip.x × screenWidth  × mouseSpeed
cursorY = indexTip.y × screenHeight × mouseSpeed
```

- 食指指尖(indexTip)的归一化坐标直接映射到屏幕像素
- `mouseSpeed` 控制移动灵敏度
- 手悬空操作，无桌面限制

### 2.3 头手融合模式

**不是 3×3 网格，而是头部偏移修正。**

头部不"选中区域"，而是提供**方向偏移量**叠加到指尖位置上：

```
# 头部姿态 → 归一化偏移向量 (-1 ~ 1)
yawOffset   = clamp(yaw / yawMax,   -1, 1)    # 左负右正
pitchOffset = clamp(pitch / pitchMax, -1, 1)   # 上负下正

# 指尖基础位置 + 头部偏移修正
cursorNormX = indexTip.x + yawOffset × gazeSensitivity × 0.2
cursorNormY = indexTip.y + pitchOffset × gazeSensitivity × 0.2

# 限制在 [0,1] 范围内
cursorNormX = clamp(cursorNormX, 0, 1)
cursorNormY = clamp(cursorNormY, 0, 1)

# 映射到屏幕
cursorX = cursorNormX × screenWidth  × mouseSpeed
cursorY = cursorNormY × screenHeight × mouseSpeed
```

**效果解释：**

| 你的操作 | 效果 |
|---------|------|
| 食指指向屏幕中间 + 头正对 | 光标在中间 |
| 食指指向屏幕中间 + 头向右转 | 光标向右偏移（偏移量 = gazeSensitivity） |
| 食指指向屏幕中间 + 头向左下 | 光标向左下偏移 |
| 食指不动 + 头转回中间 | 光标回到指尖位置 |

**本质**：指尖为主（粗定位），头部提供**精细方向修正**。头转的方向就是光标偏移的方向，偏移量由注视灵敏度控制。

### 2.4 4 个方向 vs 连续偏移

实际上技术实现上是**连续偏移**（yawOffset/pitchOffset 从 -1 到 1 连续变化），不是离散的 4 个方向。但因为 gazeSensitivity 控制偏移幅度，用户可以灵活调节：

- **高灵敏度**：头微转光标就大幅偏移 → 适合快速跨屏移动
- **低灵敏度**：头要转很多光标才偏移一点点 → 适合微调精确定位

## 三、摄像头位置自动标定

### 3.1 原理

系统通过视频画面自动反推摄像头与用户的相对位置，无需用户手动操作。

| 摄像头位置 | 画面中人脸特征 | 自然头部姿态 |
|-----------|---------------|-------------|
| 显示器**上方** | 人脸在画面偏上区域 | 用户略微仰头（pitch 偏正） |
| 显示器**下方** | 人脸在画面偏下区域 | 用户略微低头（pitch 偏负） |
| 显示器**左侧** | 人脸偏右侧 + 面部角度偏右 | 用户头略向左转（yaw 偏负） |
| 显示器**右侧** | 人脸偏左侧 + 面部角度偏左 | 用户头略向右转（yaw 偏正） |
| **正对** | 人脸居中 | yaw/pitch 对称 |

### 3.2 自动标定流程（无感执行）

```
① 启动后，前 3 秒收集 30 帧面部数据（每 5 帧取 1 次）
② 对 yaw/pitch 取均值 → 得到 baseline
③ 剔除异常值（突然转头的帧）
④ 后续所有 yaw/pitch 减去 baseline → 得到相对偏移
⑤ 使用过程中持续滑动平均微调
```

不需要你点任何按钮、做任何动作。换摄像头位置或换坐姿后自动重新适应。

## 四、预定义手势（无需录入，直接可用）

### 4.1 手势列表

| 手势 | 检测方法 | 说明 |
|------|---------|------|
| **食指单击** | indexTip.y 快速下降再回升（单次敲击 < 300ms） | 像按一个按钮 |
| **食指双击** | 两次单击间隔 < 400ms | 快速敲两下 |
| **双指按下** | indexTip.y 和 middleTip.y **同时**快速下降 | 食指+中指一起按 |
| **双指收回** | 双指同时恢复到正常位置 | 松开 |
| **上挥** | 手掌中心(wrist.y) 快速下降 + 稳定上升趋势 | 手往上抬 |
| **下挥** | 手掌中心(wrist.y) 快速上升 + 稳定下降趋势 | 手往下压 |

### 4.2 为什么不需要录入

这些手势基于**指尖位置的时间序列变化模式**，阈值参数（手势灵敏度）可调，检测逻辑固定。不需要像语音命令一样"训练模型"——开箱即用。

## 五、完整配置参数一览

### 5.1 检测参数面板（DetectionParamsView）

| 参数名 | 控件类型 | 取值范围 | 默认值 | 作用 |
|-------|---------|---------|-------|------|
| **手势灵敏度** | 滑条 | 0~1 | 0.5 | 手势触发阈值（越低越灵敏，越高越稳定） |
| **鼠标速度** | 滑条 | 0~1 | 0.5 | 手指控制光标的移动速度倍率 |
| **注视灵敏度** | 滑条 | 0~1 | 0.5 | 头部偏移对光标的修正幅度（越高头转一点光标就偏很多，ON时才有效） |
| **启用注视追踪** | 开关 | ON/OFF | ON | ON = 头手融合模式，OFF = 纯手指模式 |

**三参数在不同模式下的效果：**

| 参数 | 头手融合模式 | 纯手指模式 |
|------|------------|-----------|
| 手势灵敏度 ✅ | 控制 tap/swipe 检测阈值 | 控制 tap/swipe 检测阈值 |
| 鼠标速度 ✅ | 指尖移动映射到光标的倍率 | 指尖直接映射全屏的倍率 |
| 注视灵敏度 ✅ | 头部偏移对光标位置的修正幅度 | **灰色不可用** |

### 5.2 手势映射面板（GestureMappingView — 改造现有参照 DetectionParamsView）

每个手势可以绑定到不同的动作，所有映射可由用户自由配置：

| 手势（固定） | 默认映射动作 | 可替换成 |
|------------|------------|---------|
| 食指单击 | 鼠标左键单击 | 双击、右键、中键、无动作 |
| 食指双击 | 鼠标左键双击 | 单击、右键、打开文件、无动作 |
| 双指按下 | 拖拽开始（按住左键） | 三指拖拽、右键、滚动开始、无动作 |
| 双指收回 | 拖拽结束（释放左键） | 取消拖拽、释放、无动作 |
| 上挥 | 内容向上滚动（滚轮上滑） | 内容向下滚动、音量+、切换桌面、无动作 |
| 下挥 | 内容向下滚动（滚轮下滑） | 内容向上滚动、音量-、切换桌面、无动作 |

**可用的动作类型（ActionType）列表：**

```
- 鼠标左键单击
- 鼠标左键双击
- 鼠标右键单击
- 鼠标中键单击
- 按住左键（拖拽开始）
- 释放左键（拖拽结束）
- 滚轮上滑
- 滚轮下滑
- 滚轮左滑
- 滚轮右滑
- 按键（可指定任意系统按键）
- 触控板手势（Mission Control / Launchpad / Exposé）
- 系统快捷指令（AppleScript / Shortcuts）
- macOS 快捷键（自定义组合键）
- 无动作
```
