## 方案设计

### 核心思路：增量式 → 绝对式

```
旧架构（增量，有问题）：
  delta(手n, 手n-1) → velocity → factor → step → currentPosition += step
  问题：漂移、初始跳跃、回不了正

新架构（绝对映射）：
  手绝对位置 → 映射函数 → 光标绝对位置
  手在原点 → 光标在中心。永远。
```

### 1. 静止原点自动校准

```
手进入画面的前 N 帧（~0.5s）：
  原点 = EMA(手中心位置)

之后：
  偏移 = 手中心位置 - 原点
  光标 = 屏幕中心 + 偏移 × 屏幕尺寸 × 增益
```

| 场景 | 行为 |
|------|------|
| 手刚入画面 | 0.5s 校准期，光标不动（解决初始跳跃） |
| 校准完成 | 手在原位 → 光标在中心 |
| 手离开再回来 | 重新校准（0.5s） |
| 手在画面内持续 | 手移动 → 光标按比例移动 |

### 2. 映射函数

```swift
// CursorController 新增方法
func updateWithAbsolutePosition(
    handCenter: CGPoint,      // 归一化坐标 (0~1)
    origin: CGPoint,           // 原点（归一化坐标）
    screenSize: CGSize,
    gain: Float,               // 增益，默认 2.0
    handedness: HandSide       // 左右手
) -> CGPoint
```

映射逻辑：
```
cursor.x = screenCenter.x + (handCenter.x - origin.x) * screenSize.width * gain
cursor.y = screenCenter.y - (handCenter.y - origin.y) * screenSize.height * gain

左右手对称：
  右手自然在摄像头右侧 → origin.x ≈ 0.55
  左手自然在摄像头左侧 → origin.x ≈ 0.45
  自动检测后 origin 自动偏置
```

### 3. palmCenter 鲁棒性增强

```swift
// 当前：需要 wrist + 至少一个 MCP
// 改为：只要有一个 MCP 就可以计算粗略中心
var palmCenter: CGPoint? {
    let primary = [indexMCP, middleMCP, ringMCP, littleMCP, wrist]
    let valid = primary.compactMap { $0 }
    guard !valid.isEmpty else {
        // 降级：只用指尖
        let tips = [indexTip, middleTip].compactMap { $0 }
        guard !tips.isEmpty else { return nil }
        return average(tips)
    }
    return average(valid)
}
```

## 数据流（新）

```
摄像头帧 → HandPoseDetector
  ↓
HandPoseResult (palmCenter + chirality)
  ↓
原点校准状态机：
  [校准中] → 累积 origin EMA（0.5s）
  [跟踪中] → CursorController.updateWithAbsolutePosition(hand, origin, gain)
  [丢失]   → 重置
  ↓
computeCursor（磁吸 + 边界裁剪）
  ↓
CGWarpMouseCursorPosition
```

## 原点校准状态机

```
                手出现 + conf > 0.15
   ┌─────────┐ ─────────────────────→ ┌─────────┐
   │  空闲    │                        │ 校准中   │
   │ (idle)  │ ←──── 手丢失 ──────── │(calib)  │
   └─────────┘                        └────┬────┘
                                          │ 累积 0.5s 后
                                          ↓
                                     ┌─────────┐
                                     │ 跟踪中   │
                                     │(track)  │
                                     └────┬────┘
                                          │ 手丢失 > 15帧
                                          ↓
                                     ┌─────────┐
                                     │  空闲    │
                                     └─────────┘
```

## 校准期的光标行为

| 阶段 | 光标动作 |
|------|---------|
| 校准中（前 0.5s） | **完全不动**（解决初始跳跃） |
| 跟踪中 | 绝对位置映射 |
| 丢失（<15帧） | 继续输出最后位置 |
| 丢失（>15帧） | 重置，光标停止移动 |
