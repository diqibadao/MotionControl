# MotionControl 配置测试区设计

> 每个配置项修改后，用户能在测试区**实时看到/感受到效果**

---

## 总原则

配置面板中，每个参数修改后**即时生效**，并在测试区给出可视化反馈。

```
修改阈值 ─→ 效果视觉化 ─→ 确认 OK → 关闭面板继续使用
```

---

## 各配置项的测试反馈

### 1. 手势阈值（捏合阈值）

| 配置项 | 测试效果展示 |
|--------|------------|
| `pinchThreshold` | 在预览画面中叠加显示拇指-食指距离实时数值 + 阈值线 |
| `gestureCooldown` | 显示手势事件的时间戳和冷却倒计时条 |
| `doubleTapWindow` | 显示两次捏合的时间间隔 |

**UI 设计：**

## 实施任务

将以下任务追加到实施计划 M6：

### Task 6.x: 配置测试区

**Files:**
- Create/Modify: `MotionControl/Views/ConfigTestView.swift`
- Modify: `MotionControl/Views/ConfigPanel.swift`

**包含子视图：**
- `ThresholdTestView` — 捏合阈值实时显示
- `MouseTestView` — 灵敏度和平滑测试
- `GazeTestView` — 注视追踪测试
- `MouthTestView` — 嘴型检测测试
- `VoiceTestView` — 语音识别测试
- `GestureMappingTestView` — 手势映射实时验证

**原则：**
- 每个测试区在配置面板底部全局可见
- 修改任意参数 → 测试区数值/波形/光标实时变化
- 用户修改完后可在测试区确认效果再保存
