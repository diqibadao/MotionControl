## 日志分析结论

| 现象 | 日志证据 | 根因 |
|------|---------|------|
| 鼠标在动但抖动 | 帧间 handTip 变化约 0.001-0.005 norm | 无防抖算法 |
| 注视无效果 | `yaw=0.0 pitch=nil` 始终如此 | DetectionPipeline 跳过 GazeEstimator |
| 手势全 none | 每次 `type=none` | 时间序列检测未匹配 |
| 人脸检测慢 | 每帧 6-12 秒 | 可能 VNRequest 性能问题 |

## 解决方案

### 1. 鼠标防抖（Cursor Smoothing）

**方案**：在 `CursorController.computeCursor` 中增加指数平滑 + 死区过滤。

```
指数平滑：smoothedPos = prevPos * 0.7 + newPos * 0.3
死区过滤：if |newPos - prevPos| < minMovePixels → 不移动
```

参数可调（平滑因子、最小移动像素）。

**涉及文件**：`Control/CursorController.swift`

### 2. 食指伸出才控制鼠标

**方案**：在 `CursorController.updateHandTip` 之前检查食指是否在"指点"状态。

判定逻辑：
```
indexLen = dist(indexTip, wrist)
avgOtherLen = avg(dist(middleTip,wrist), dist(ringTip,wrist), dist(littleTip,wrist))
isPointing = indexLen > avgOtherLen * 1.5 && indexLen > minLen
```

如果不是 pointing 状态 → 不更新 handTip（光标停在当前位置）。

**涉及文件**：`App/MotionControlApp.swift`（在 onHandResult 回调中加判断）

### 3. 恢复 GazeEstimator 使用

**方案**：DetectionPipeline.didOutputFace 改为使用 GazeEstimator，并在启动时调用 autoCalibrate()。

改动点：
- `DetectionPipeline.swift` — `didOutputFace` 调用 `await gazeEstimator.estimate(from: face)` 而不是直接创建 GazeEstimate
- `DetectionPipeline.swift` — 新增 `startGazeCalibration()` 方法，调用 `await gazeEstimator.autoCalibrate()`
- `MotionControlApp.swift` — `onAppear` 中调用 `detectionPipeline.startGazeCalibration()`

### 4. 默认手势映射为无动作

**方案**：将 `GestureConfig.defaultMapping()` 中 INDEX_TAP/INDEX_DOUBLE_TAP/DUAL_TAP/DUAL_RELEASE 的 actionType 改为 `.noAction`。
