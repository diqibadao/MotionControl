### Task 2: 创建 App 入口

**Files:**
- Create: `MotionControl/App/MotionControlApp.swift`
- Create: `MotionControl/App/ContentView.swift`
- Create: `MotionControl/App/SystemState.swift`

**Code — MotionControlApp.swift:**
```swift
import SwiftUI

@main
struct MotionControlApp: App {
    @State private var systemState = SystemState()
    
    var body: some Scene {
        MenuBarExtra("MotionControl", systemImage: "hand.raised") {
            StatusMenuView(state: systemState)
        }
        
        Window("MotionControl 配置", id: "config") {
            ConfigPanelView(state: systemState)
        }
        .windowResizability(.contentSize)
        
        Window("摄像头预览", id: "preview") {
            CameraPreviewView(state: systemState)
        }
    }
}
```

**Code — SystemState.swift:**
```swift
import SwiftUI

@Observable
class SystemState {
    var cameraState: CameraState = .stopped
    var handDetected: Bool = false
    var faceDetected: Bool = false
    var currentGesture: String = "—"
    var gazeActive: Bool = false
    var gazePosition: CGPoint = .zero
    var voiceState: VoiceState = .idle
    var voiceText: String = ""
    var fps: Double = 0
    
    var permission: PermissionStatus = PermissionStatus()
}

enum CameraState: String { case stopped, starting, running, failed }
enum VoiceState: String { case idle, listening, processing }

struct PermissionStatus {
    var camera: Bool = false
    var microphone: Bool = false
    var speech: Bool = false
    var accessibility: Bool = false
}
```

## 执行顺序

```
M1 (项目脚手架)
  ↓
M2 (摄像头采集)
  ↓
M3 (手部+手势+鼠标)  ←  MVP 核心可用
  ↓
M4 (人脸+注视+嘴型)
  ↓
M5 (语音识别+文字输入)
  ↓
M6 (三合一整合+UI)
  ↓
M7 (上架准备)
```

**MVP 红线**：M1+M2+M3 完成 = 手势控制笔记本 + 摄像头预览可用。之后的 M4/M5 是增强功能。
