### 分层职责

| 层级 | 职责 | 关键技术 |
|------|------|---------|
| **Input** | 原始数据采集 | AVCaptureSession, AVCaptureVideoDataOutput, SFSpeechRecognizer |
| **Analysis** | CV 检测 + 语义分析 | VNRequest, VNSequenceRequestHandler, 帧级推理 |
| **Control** | 系统级操作 | CGEvent, CursorOverlay (NSWindow+Metal) |
| **UI** | 用户界面 | SwiftUI, NSViewRepresentable, MenuBarExtra |

## 2. 核心数据流

### 2.1 每帧处理管道

```
CMSampleBuffer (from AVCapture)
     │
     ├──→ HandPoseDetector.detect()
     │       ↓
     │    handLandmarks[0..20]
     │       ↓
     │    GestureAnalyzer.analyze(landmarks) → gestureType
     │       ↓
     │    MouseController.updatePosition(gestureType, handPosition)
     │
     ├──→ FaceMeshDetector.detect()
     │       ↓
     │    faceLandmarks[0..75]
     │       ↓
     │    ├──→ GazeEstimator.estimate(landmarks)
     │    │       ↓
     │    │    gazePoint (screen coordinate)
     │    │       ↓
     │    │    CursorOverlay.showGazePoint(gazePoint)
     │    │
     │    └──→ VoiceInputManager.checkMouth(landmarks)
     │            ↓
     │         mouthStatus (OPEN / CLOSED)
     │            ↓
     │         VoiceRecognizer.start() / stop()
     │            ↓
     │         MouseController.typeText(text)
     │
     └──→ (optional) Render preview to Metal layer
```

### 2.2 帧内执行顺序（严格）

```
1. AVCaptureVideoDataOutput 回调 → CMSampleBuffer
2. VNSequenceRequestHandler.perform([handPoseRequest, faceRequest])
3. 解析 handPoseRequest.results → handLandmarks
4. 解析 faceRequest.results → faceLandmarks
5. GestureAnalyzer(handLandmarks) → gestureType
6. GazeEstimator(faceLandmarks) → gazePoint
7. MouthDetector(faceLandmarks) → mouthStatus
8. MouseController(gestureType, gazePoint) → CGEvent(s)
9. VoiceInputManager(mouthStatus) → start/stop speech
10. 下一帧
```

**Vision Framework 特点**：多个 VNRequest 可以合并到一次 `perform()` 调用，由 Vision 内部并行化处理，性能更好。

### 3.2 HandPoseDetector

```swift
class HandPoseDetector {
    private let request = VNDetectHumanHandPoseRequest()
    
    init() {
        request.maximumHandCount = 1  // 只检测单手
    }
    
    func detect(in pixelBuffer: CVPixelBuffer) throws -> HandPose? {
        let handler = VNSequenceRequestHandler()
        try handler.perform([request], on: pixelBuffer)
        
        guard let observation = request.results?.first,
              let landmarks = try? observation.recognizedPoints(.all) else {
            return nil
        }
        
        return HandPose(observation: observation, landmarks: landmarks)
    }
}
```

### 3.3 FaceMeshDetector

```swift
class FaceMeshDetector {
    private let request = VNDetectFaceLandmarksRequest()
    
    func detect(in pixelBuffer: CVPixelBuffer) throws -> FaceData? {
        // 同一帧内可以和 handPoseRequest 合并
        let handler = VNSequenceRequestHandler()
        try handler.perform([request], on: pixelBuffer)
        
        guard let face = request.results?.first else { return nil }
        
        return FaceData(
            landmarks: face.landmarks,
            roll: face.roll?.floatValue ?? 0,
            pitch: face.pitch?.floatValue ?? 0,
            yaw: face.yaw?.floatValue ?? 0
        )
    }
}
```

### 3.5 GazeEstimator

```swift
class GazeEstimator {
    private let smoothFactor: Float = 0.4
    private var smoothedGaze: CGPoint?
    
    func estimate(from face: FaceData, screenSize: CGSize) -> CGPoint {
        // 1. 提取眼睑轮廓 → 瞳孔相对位置
        let leftEye = face.landmarks?.leftEye
        let rightEye = face.landmarks?.rightEye
        
        // 2. 计算瞳孔在眼框内的偏移（0~1）
        let leftPupilRatio = pupilOffset(leftEye)
        let rightPupilRatio = pupilOffset(rightEye)
        
        // 3. 结合头部姿态
        let yawFactor = face.yaw / 30.0  // ±30度 → ±1
        let pitchFactor = face.pitch / 30.0
        
        // 4. 映射到屏幕坐标
        let screenX = (0.5 + yawFactor * gazeSensitivity + leftPupilRatio * 0.1) * screenSize.width
        let screenY = (0.5 - pitchFactor * gazeSensitivity) * screenSize.height
        
        // 5. 指数平滑
        let raw = CGPoint(x: screenX, y: screenY)
        smoothedGaze = smoothedGaze.map { 
            CGPoint(
                x: $0.x * (1 - smoothFactor) + raw.x * smoothFactor,
                y: $0.y * (1 - smoothFactor) + raw.y * smoothFactor
            )
        } ?? raw
        
        return smoothedGaze!
    }
}
```

### 3.8 CursorOverlay

- 独立 NSWindow（浮层模式）
- 不接收焦点（ignoresMouseEvents = true）
- level = .floating
- 在 NSView 中用 CGContext 或 Metal 绘制手势光标和注视光标
- 双光标样式区分：
  - 手势光标：圆形 + 颜色变化（绿色→正常，红色→点击）
  - 注视光标：半透明十字准星或瞄准环

## 4. 关键技术决策

### 4.1 为什么用 Vision Framework 而不是 MediaPipe？
| 方面 | Vision Framework | MediaPipe |
|------|----------------|-----------|
| 审核合规 | ✅ 系统框架，无需额外说明 | ❌ 需要声明第三方库 |
| 性能 | ✅ 系统优化，Apple Silicon 加速 | ⚠️ 通用框架 |
| 包体积 | ✅ 零体积 | ❌ 约 10-30MB |
| 集成难度 | ✅ 直接调用 | ⚠️ 需要 C++ 桥接或 Pod |
| 手势精度 | ✅ 21 两点足够 | ✅ 21 点相同 |

### 4.2 为什么用 CGEvent 而不是 Accessibility API？
| 方面 | CGEvent | Accessibility API |
|------|---------|-----------------|
| 鼠标控制 | ✅ 精确坐标 + 左/右/中键 | ✅ 支持 |
| 键盘控制 | ✅ 支持 | ✅ 支持 |
| 文本输入 | ✅ CGEventPostKeyboardEvent | ❌ 不支持 |
| 响应速度 | ✅ 系统级，快 | ⚠️ 需要 IPC |
| 权限要求 | ⚠️ 辅助功能 | ⚠️ 辅助功能 |

**决策**：CGEvent 更底层、更灵活，文本输入也必须用 CGEvent。

### 4.3 检测频率策略
- Vision 推理最耗时，不可每帧都跑
- 策略：渲染帧（显示预览）和检测帧（手部/面部推理）分离
- 检测帧率：15fps（每 2 帧跑一次检测）
- 渲染帧率：30fps（中间帧复用上次检测结果 + 光标插值）

## 5. 线程模型

```
主线程 (UI)         检测线程         控制线程
    │                  │                │
    │    ┌─────────────┼─────┐          │
    │    │ AVCapture    │     │          │
    │    │ VideoData    │     │          │
    │    │ Output 回调   │     │          │
    │    └──────┬───────┘     │          │
    │           │             │          │
    │    ┌──────┴───────┐     │          │
    │    │ VNRequest     │     │          │
    │    │ Perform()     │     │          │
    │    └──────┬───────┘     │          │
    │           │             │          │
    │    ┌──────┴───────┐     │          │
    │    │ 分析结果回调    │     │          │
    │    └──────┬───────┘     │          │
    │           │             │          │
    │    DispatchQueue.main  │          │
    │    .async {            │          │
    │      UI 更新           │          │
    │      CGEvent 调用      │          │
    │    }                   │          │
```

- **检测线程**：VNSequenceRequestHandler 后台执行
- **控制线程**：CGEvent 必须在主线程或同一线程连续执行（这里放主线程）
- **UI 线程**：SwiftUI 更新
