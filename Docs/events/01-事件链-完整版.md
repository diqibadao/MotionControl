# MotionControl 详细事件链（功能拆解）

> 用途：开发对齐 / 联调/测试/跟踪 / 日志模板
> 每个事件 = 独立可测试单元

---

## 目录

| 事件编号 | 事件名 | 模块 | 依赖 |
|---------|--------|------|------|
| E01 | 权限申请与检测 | Input | 无 |
| E02 | 摄像头采集 | Input | E01 |
| E03 | 手部关键点检测 | Detection | E02 |
| E04 | 人脸关键点检测 | Detection | E02 |
| E05 | 手势分析 | Detection | E03 |
| E06 | 注视点估计 | Detection | E04 |
| E07 | 嘴型检测 | Detection | E04 |
| E08 | 鼠标控制 | Control | E05, E06 |
| E09 | 键盘与快捷键控制 | Control | E05 |
| E10 | 语音识别 | Voice | E07 |
| E11 | 文字输入 | Voice | E10 |
| E12 | 配置管理 | Config | 无 |
| E13 | 系统托盘与UI | UI | 全部 |

## E01 — 权限申请与检测

### 触发条件
- App 首次启动 / 用户进入设置页 / 功能运行时检测到权限缺失

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| 无 | — | 系统 | 调用各框架的 authorization API |

### 处理步骤

```
1. 检测摄像头权限
   └→ AVCaptureDevice.authorizationStatus(for: .video)
       ├── .authorized       → 标记 cameraGranted = true
       ├── .denied           → 标记 cameraGranted = false, 记录"需去系统设置开启"
       ├── .restricted       → 标记 cameraGranted = false, 记录"设备限制"
       └── .notDetermined    → 请求授权 AVCaptureDevice.requestAccess(for: .video)
                              └→ 回调更新 cameraGranted

2. 检测麦克风权限
   └→ AVCaptureDevice.authorizationStatus(for: .audio)
       ├── .authorized       → 标记 micGranted = true
       ├── .denied           → 标记 micGranted = false, 记录
       ├── .restricted       → 标记 micGranted = false
       └── .notDetermined    → 请求授权 AVCaptureDevice.requestAccess(for: .audio)
                              └→ 回调更新 micGranted

3. 检测语音识别权限
   └→ SFSpeechRecognizer.authorizationStatus()
       ├── .authorized       → 标记 speechGranted = true
       ├── .denied           → 标记 speechGranted = false
       ├── .restricted       → 标记 speechGranted = false
       └── .notDetermined    → SFSpeechRecognizer.requestAuthorization()
                              └→ 回调更新 speechGranted

4. 检测辅助功能权限（CGEvent 必需）
   └→ AXIsProcessTrustedWithOptions(nil)
       ├── true              → 标记 accessibilityGranted = true
       └── false             → 标记 accessibilityGranted = false
                               → 记录"需手动开启：系统设置→隐私→辅助功能→MotionControl"
```

### 输出

```swift
struct PermissionStatus {
    var cameraGranted: Bool
    var micGranted: Bool
    var speechGranted: Bool
    var accessibilityGranted: Bool
    var allRequired: Bool { cameraGranted && accessibilityGranted }
    var voiceAvailable: Bool { micGranted && speechGranted }
}
```

### 状态机

```
initial → 请求摄像头 → 请求麦克风 → 请求语音 → 检测辅助功能 → 完成
               ↓            ↓           ↓            ↓
           拒绝/允许     拒绝/允许    拒绝/允许    未勾选/已勾选
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 全部权限已授权 | 静默跳过，进入 E02 | `[E01] all permissions granted` |
| 摄像头拒绝 | 禁用手势+注视，仅可用语音 | `[E01] camera denied, disabling gesture` |
| 辅助功能未勾选 | 弹窗引导用户去系统设置 | `[E01] accessibility not granted, prompting user` |
| 首次启动全部 notDetermined | 依次弹窗请求 | `[E01] first launch, requesting all permissions` |
| 用户在设置中关闭权限后返回 | 通过 applicationDidBecomeActive 重新检测 | `[E01] re-check on becomeActive` |

### 日志模板

```
[E01] ── 权限检测 ──
  camera:       authorized ✓
  mic:          authorized ✓
  speech:       authorized ✓
  accessibility: granted ✓
  result:       all_ok, entering E02
```

### 验证测试

| 测试项 | 操作 | 预期 |
|--------|------|------|
| 首次启动弹窗 | 安装后首次打开 | 摄像头→麦克风→语音 依次弹窗 |
| 拒绝摄像头 | 弹窗选"不允许" | 禁用摄像头预览，禁用手势/注视 |
| 拒绝麦克风 | 弹窗选"不允许" | 禁用语音输入，状态显示不可用 |
| 辅助功能未勾选 | 不勾选 | 弹窗提示+引导按钮 |
| 权限恢复 | 去系统设置重新开启 | App 自动恢复功能 |

## E02 — 摄像头采集

### 触发条件
- E01 完成且 cameraGranted = true
- 用户点击"开始" / App 自动启动

### 输入
| 参数 | 类型 | 来源 | 默认值 |
|------|------|------|--------|
| deviceID | String? | E12 Config | nil（自动选择） |
| resolution | CGSize | E12 Config | {640, 480} |
| frameRate | Int | E12 Config | 30 |

### 处理步骤

```
1. 发现设备
   └→ AVCaptureDevice.DiscoverySession(.video)
       ├── deviceID 指定 → 使用指定设备
       └── deviceID 为空 → 使用默认设备
       └── 无设备       → 抛出 CameraError.noDevice

2. 配置 AVCaptureSession
   a. 创建 AVCaptureDeviceInput(from: device)
      └→ 失败 → CameraError.inputError
   b. 创建 AVCaptureVideoDataOutput
      └→ 设置 pixelFormat = kCVPixelFormatType_32BGRA
      └→ 设置 videoSettings = [kCVPixelBufferPixelFormatTypeKey: kCVPixelFormatType_32BGRA]
      └→ 设置 sampleBufferDelegate = self
         queue = cameraQueue (串行队列, qos: .userInitiated)
   c. 设置 sessionPreset = .medium（640×480）
   d. 配置帧率 → 锁定设备配置 setActiveVideoMinFrameDuration

3. 启动
   └→ session.startRunning()
       └→ 异步，等待 firstFrame 信号

4. 输出帧
   └→ captureOutput(_:didOutput:from:) 回调
       └→ 将 CMSampleBuffer 入帧队列
       └→ 触发 E03 / E04（检测线程取帧）
```

### 输出

```swift
protocol CameraOutput: AnyObject {
    func cameraDidOutput(pixelBuffer: CVPixelBuffer, timestamp: CMTime)
    func cameraDidFail(error: CameraError)
}

enum CameraError: Error {
    case noDevice
    case inputError(Error)
    case sessionError(Error)
    case permissionDenied
}
```

### 状态机

```
stopped → configuring → running → failed
   ↑          |             |        |
   └──────────┴─────────────┴────────┘
          (stop/restart)
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 无摄像头设备 | 不可恢复，禁用所有视觉功能 | `[E02] no camera device found` |
| 摄像头被其他 App 占用 | 重试 3 次，每次 1s | `[E02] device busy, retry 1/3` |
| session 启动超时（5s） | 停止并报错 | `[E02] session start timeout` |
| 热插拔摄像头 | 监听 AVCaptureDeviceWasConnectedNotification，自动切换 | `[E02] device connected/disconnected` |
| 帧率不足（< 10fps） | 降低分辨率到 480×360 | `[E02] low frame rate, downgrading` |

### 日志模板

```
[E02] ── 摄像头采集 ──
  device:  Logitech C920e (USB Video Device)
  resolution: 640×480
  framerate:  30fps
  state:      running ✓
  frame#:     1247
  avg_latency: 16ms
```

### 验证测试

| 测试 | 步骤 | 预期 |
|------|------|------|
| 基础采集 | 启动 App | 摄像头预览画面正常显示 |
| 帧率稳定 | 运行 60s | 平均帧率 > 25fps |
| 分辨率匹配 | 输出帧尺寸 | 640×480 |
| 热插拔 | 运行时拔掉/插回 C920e | 画面黑屏→自动恢复 |
| 多摄像头 | 有内置 + C920e | 自动选 C920e（或按配置选） |

## E03 — 手部关键点检测

### 触发条件
- E02 正常输出帧
- 检测间隔：每 N 帧执行一次（默认每 2 帧 = 15fps）

### 输入

| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| pixelBuffer | CVPixelBuffer | E02 | BGRA 格式视频帧 |
| orientation | CGImagePropertyOriation | E02 | 根据设备方向 |

### 处理步骤

```
1. 创建 VNDetectHumanHandPoseRequest（复用）
   └→ maximumHandCount = 1

2. 执行检测
   └→ VNSequenceRequestHandler.perform([handPoseRequest], on: pixelBuffer)
       └→ 需要时创建新 handler（handler 可复用跨帧）

3. 解析结果
   └→ handPoseRequest.results?.first
       ├── nil → 未检测到手 → 输出 .none
       └── observation →
           ├── chirality: .left / .right
           └── recognizedPoints(.all) →
               ├── wrist             → 手腕位置
               ├── thumbTip / thumbIP / thumbMP / thumbCMC  → 拇指 4 点
               ├── indexTip / indexDIP / indexPIP / indexMCP  → 食指 4 点
               ├── middleTip / middleDIP / middlePIP / middleMCP → 中指 4 点
               ├── ringTip / ringDIP / ringPIP / ringMCP      → 无名指 4 点
               └── littleTip / littleDIP / littlePIP / littleMCP  → 小指 4 点
    
4. 坐标转换
   └→ Vision 坐标（归一化 0~1，y 轴向上）→ AVFoundation 坐标（像素，y 轴向下）
       像素 x = normalizedX * pixelBufferWidth
       像素 y = (1 - normalizedY) * pixelBufferHeight

5. 过滤低置信度
   └→ confidence < 0.5 → 丢弃该点
   └→ 如果所有点都丢弃 → 输出 .none

6. 输出 HandPose
   └→ 传递给 E05
```

### 输出

```swift
struct HandPose {
    enum Chirality { case left, right, unknown }
    
    let chirality: Chirality
    let wrist: CGPoint?
    // 每根手指 4 个关节
    let thumb: [CGPoint]   // [TIP, IP, MP, CMC]
    let index: [CGPoint]   // [TIP, DIP, PIP, MCP]
    let middle: [CGPoint] 
    let ring: [CGPoint]
    let little: [CGPoint]
    // 所有 21 个原始点
    let allPoints: [VNRecognizedPoint]
    // 是否检测到
    var detected: Bool { wrist != nil }
}
```

### 状态机

```
每帧: 检测 → 有手 → 输出 HandPose → E05
         → 无手 → 输出 .none → E05
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 连续 30 帧无手 | 输出 idle 状态 | `[E03] no hand for 30 frames, entering idle` |
| 检测器报错 | 跳过当前帧，下一帧重试 | `[E03] detection error, skipping frame` |
| 置信度全部 < 0.5 | 视为无手 | `[E03] all points low confidence` |
| 同时出现多只手 | 只取 confidence 最高的一只 | `[E03] multiple hands, picking highest confidence` |
| 手部部分遮挡 | 可见点正常输出，缺失点标记 nil | `[E03] partial hand detected` |

### 日志模板

```
[E03] ── 手部检测 ──
  frame#:     1247
  detected:   true ✓
  chirality:  right
  confidence: 0.91
  wrist_pos:  (320, 240)
  thumb_tip:  (300, 180)
  index_tip:  (350, 160)
  latency:    24ms
```

### 验证测试

| 测试 | 步骤 | 预期 |
|------|------|------|
| 基础检测 | 手掌正对摄像头 | 检测到手，21 点正确 |
| 无手状态 | 手移出画面 | `detected = false` |
| 部分遮挡 | 手指交叉 | 可见点正常 |
| 左右手 | 伸左手/右手 | chirality 正确识别 |
| 近距离 | 手靠近摄像头 | 检测到，但部分点可能超出画面 |
| 远距离 | 手远离摄像头（>2m） | 可能检测不到 |

## E04 — 人脸关键点检测

### 触发条件
- E02 正常输出帧
- 与 E03 同帧执行（合并到一次 VNSequenceRequestHandler.perform）

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| pixelBuffer | CVPixelBuffer | E02 | 同 E03 |

### 处理步骤

```
1. 创建 VNDetectFaceLandmarksRequest（复用）
   └→ constellation = .constellation76Points（Revision 3 支持）

2. 执行检测（与 E03 合并到一次 perform）
   └→ VNSequenceRequestHandler.perform([handPoseRequest, faceRequest], on: pixelBuffer)

3. 解析结果
   └→ faceRequest.results?.first
       ├── nil → 未检测到人脸 → 输出 .none
       └── observation →
           ├── 头部姿态: roll / pitch / yaw（Float?）
           ├── 面部轮廓: faceContour → normalizedPoints
           ├── 左眼: leftEye → normalizedPoints（~6 点）
           ├── 右眼: rightEye → normalizedPoints（~6 点）
           ├── 左瞳孔: leftPupil → normalizedPoints（1 点）
           ├── 右瞳孔: rightPupil → normalizedPoints（1 点）
           ├── 外唇: outerLips → normalizedPoints（~16 点）
           ├── 内唇: innerLips → normalizedPoints（~12 点）
           ├── 左眉: leftEyebrow
           ├── 右眉: rightEyebrow
           └── 鼻子: nose / noseCrest

4. 坐标转换
   └→ 归一化坐标 → 像素坐标（同 E03）

5. 输出 FaceData
   └→ 传递给 E06 / E07
```

### 输出

```swift
struct FaceData {
    let detected: Bool
    // 头部姿态（弧度）
    let roll: Float?    // 左右歪头
    let pitch: Float?   // 上下点头
    let yaw: Float?     // 左右转头
    // 眼睑轮廓（像素坐标）
    let leftEye: [CGPoint]?
    let rightEye: [CGPoint]?
    // 瞳孔位置（像素坐标）
    let leftPupil: CGPoint?
    let rightPupil: CGPoint?
    // 嘴唇轮廓
    let outerLips: [CGPoint]?   // 16 点
    let innerLips: [CGPoint]?   // 12 点
    // 其他参考点
    let faceContour: [CGPoint]?
    let nose: [CGPoint]?
    let medianLine: [CGPoint]?
}
```

### 状态机

```
每帧: 检测 → 有人脸 → 输出 FaceData → E06, E07
         → 无人脸 → 输出 .none → E06, E07（注视消失，嘴型消失）
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 人脸被遮挡 > 30 帧 | 注视光标消失 | `[E04] face lost for 30 frames` |
| 多人脸 | 只取 boundingBox 最大的（最近的人） | `[E04] multiple faces, picking largest` |
| 侧脸（yaw > 45°） | 单侧眼可能不可见 → 单眼注视 | `[E04] profile face, single eye tracking` |
| 低头/抬头过大（pitch > 30°） | 嘴型/瞳孔可能不可见 | `[E04] extreme pitch, landmarks may be partial` |
| 置信度低 | 跳过当前帧 | `[E04] low confidence face` |

### 日志模板

```
[E04] ── 人脸检测 ──
  frame#:     1247
  detected:   true ✓
  roll:       -2.1°
  pitch:      5.3°
  yaw:        -1.8°
  left_pupil: (280, 310)
  right_pupil:(360, 308)
  mouth_open: 0.72
  latency:    32ms
```

### 验证测试

| 测试 | 步骤 | 预期 |
|------|------|------|
| 基础检测 | 正对摄像头 | 检测到人脸 + 76 点 |
| 无人脸 | 离开画面 | `detected = false` |
| 头部转动 | 左右转头 | yaw 值变化，注视点跟随 |
| 瞳孔定位 | 眼睛看不同方向 | pupil 位置变化 |
| 多人脸 | 两人入镜 | 只跟踪最近的一个 |
| 戴口罩 | 口罩遮下半脸 | 嘴型 points 可能不完整 |

## E05 — 手势分析

### 触发条件
- E03 输出 HandPose（detected = true）

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| handPose | HandPose | E03 | 21 个手部关键点 |
| config | GestureConfig | E12 | 阈值 + 映射表 |

### 处理步骤

```
1. 计算所有手指尖和关节的距离
   └→ 拇指尖 ↔ 食指尖距离
   └→ 拇指尖 ↔ 中指尖距离
   └→ 食指尖 ↔ 掌根距离
   └→ 中指尖 ↔ 掌根距离
   └→ 无名指尖 ↔ 掌根距离
   └→ 小指尖 ↔ 掌根距离

2. 逐手势判定（按优先级从高到低）
   ┌────────────────────────────────────────────────────┐
   │ GRAB:   thumbTip↔indexTip < pinchThreshold         │
   │ PINCH:  thumbTip↔middleTip < pinchThreshold        │
   │         AND indexTip→wrist > extendThreshold       │
   │ FIST:   所有指尖→wrist < fistThreshold             │
   │ PEACE:  indexTip+wrist > ext AND middleTip+wrist > │
   │         ext AND ringTip+wrist < curlThreshold      │
   │         AND littleTip+wrist < curlThreshold        │
   │ THUMBS_UP: thumbTip→wrist > ext AND other 4 < curl │
   │ OK:     thumbTip↔indexTip < pinchThreshold         │
   │         AND middle/ring/little extended            │
   │ OPEN:   所有指尖→wrist > extendThreshold           │
   │ POINT:  indexTip→wrist > ext AND others < curl     │
   │ DRAG:   POINT + 持续移动                           │
   │ OPEN_PALM: OPEN + 五指完全张开                      │
   │ FIVE_PINCH: 5 指尖聚合到一点                        │
   └────────────────────────────────────────────────────┘

3. 挥手检测（累加器，跨帧判断）
   └→ 记录最近 5 帧的手掌中心位置
   └→ 计算水平/垂直累计位移
   └→ 累计位移 > swipeThreshold → 判定 SWIPE_{方向}
   └→ 清空累加器

4. 双击检测
   └→ 上次 GRAB 事件时间戳
   └→ 当前 GRAB 时间戳 - 上次 < doubleTapWindow
   └→ → DBL_PINCH

5. 冷却
   └→ 同一种手势在 cooldown 时间内不重复触发

6. 输出 GestureEvent
```

### 输出

```swift
struct GestureEvent {
    let type: GestureType
    let handPose: HandPose
    let confidence: Float
    let timestamp: Date
    let handPosition: CGPoint  // 掌心/手腕像素坐标
    let isRepeat: Bool         // 冷却期内
}

enum GestureType: String {
    case none
    case open           // 张开五指
    case point          // 单指点
    case grab           // 捏合拇指+食指
    case pinch          // 捏合拇指+中指
    case doublePinch    // 快速两次捏合
    case peace          // 剪刀手 V
    case fist           // 握拳
    case swipeLeft, swipeRight, swipeUp, swipeDown
    case openPalm       // 五指张开推掌
    case fivePinch      // 五指捏合
    case drag           // 单指拖拽
    case thumbsUp       // 竖大拇指
    case ok             // OK 手势
}
```

### 状态机

```
none → OPEN (五指张开) → GRAB (捏合) → DBL_PINCH (双击) → none
     → POINT (单指) → DRAG (拖拽) → none
     → PEACE (剪刀手) → 滚动模式 → none
     → SWIPE_* → none
     → FIST → Enter → none
     → THUMBS_UP → QuickLook → none
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 同时满足多个手势 | 按优先级选最高的 | `[E05] multiple gesture candidates, picked GRAB` |
| 置信度 < 0.3 | 忽略 | `[E05] confidence too low, ignoring` |
| 手势快速切换 | 冷却期内保持上一个手势 | `[E05] cooldown active, suppressing` |
| 抖动导致误判 | 移动平滑 + 阈值滞回 | `[E05] jitter detected, applying hysteresis` |

### 日志模板

```
[E05] ── 手势分析 ──
  frame#:     1247
  gesture:    GRAB
  confidence: 0.87
  hand_pos:   (320, 240) → screen(960, 540)
  thumb_index_dist: 32px (threshold: 40)
  cooldown:   inactive
  swipe_delta: x=0, y=0
```

### 验证测试

## E06 — 注视点估计

### 触发条件
- E04 输出 FaceData（detected = true）

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| faceData | FaceData | E04 | 瞳孔 + 头部姿态 |
| screenSize | CGSize | 系统 | NSScreen.main.frame.size |
| config | GestureConfig | E12 | gazeSensitivity, gazeSmoothFactor |

### 处理步骤

```
1. 获取瞳孔位置（优先使用）
   └→ leftPupil / rightPupil
   └→ 如果只有一只眼可见 → 单眼推算
   └→ 两只眼都不可见 → 面部中心推算

2. 计算瞳孔在眼框内的相对偏移
   └→ 左眼偏移 = (leftPupil - leftEyeCenter) / leftEyeWidth
   └→ 右眼偏移 = (rightPupil - rightEyeCenter) / rightEyeWidth
   └→ 平均偏移 = (左 + 右) / 2

3. 结合头部姿态（核心公式）
   └→ 基础方向 = yawFactor (yaw / 30°, 归一化±1) × pitchFactor (pitch / 30°)
   └→ 微调 = 瞳孔偏移 × gazeSensitivity × 0.15
   └→ 屏幕坐标:
       screenX = (0.5 + yawFactor × gazeSensitivity + 平均偏移.x × 0.1) × screenSize.width
       screenY = (0.5 - pitchFactor × gazeSensitivity) × screenSize.height

4. 指数平滑
   └→ smoothed = previous × (1 - smoothFactor) + raw × smoothFactor
   └→ smoothFactor 默认 0.4

5. 边界钳制
   └→ screenX = clamp(screenX, 0, screenSize.width)
   └→ screenY = clamp(screenY, 0, screenSize.height)

6. 输出 GazePoint
```

### 输出

```swift
struct GazePoint {
    let screenPosition: CGPoint     // 注视屏幕坐标
    let confidence: Float           // 0~1
    let rawPosition: CGPoint        // 平滑前原始坐标
    let targetElement: Any?         // 可选的元素检测（通过 accessibility API）
}
```

### 状态机

```
每帧: 有人脸 → 瞳孔可见 → 注视点估算
               瞳孔不可见 → 头部姿态估算（精度下降）
      无人脸 → 注视点消失 → 回到上次位置（1s 后完全消失）
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 无瞳孔点 | 仅用头部姿态（yaw/pitch） | `[E06] pupils unavailable, using head pose only` |
| 置信度 < 0.3 | 不更新注视点 | `[E06] low confidence gaze, keeping previous` |
| 用户闭眼 | 无瞳孔 → 暂停 | `[E06] eyes closed, gaze paused` |
| 突然跳跃（> 屏幕 50%） | 视为异常，忽略 | `[E06] outlier gaze jump detected, ignoring` |
| 多显示器 | 在主屏幕范围内计算 | `[E06] multi-monitor, using primary screen` |

### 日志模板

```

  face:       detected ✓
  pupils:     left(0.48,0.52), right(0.51,0.49)
  yaw:        -1.8°  pitch: 5.3°

  confidence: 0.78
```

|------|------|------|

| 闭眼 | 闭上眼睛 | 注视光标 1s 后消失 |

## E07 — 嘴型检测

### 触发条件
- E04 输出 FaceData（detected = true）

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| outerLips | [CGPoint] | E04 | 16 点嘴部外轮廓 |
| innerLips | [CGPoint] | E04 | 12 点嘴部内轮廓 |
| config | GestureConfig | E12 | openThreshold, closeThreshold, debounce |

### 处理步骤

```
1. 提取嘴部关键点
   └→ 上唇中点 ≈ outerLips 在 y 轴最小的点（或 outerLips[0]）
   └→ 下唇中点 ≈ outerLips 在 y 轴最大的点（或 outerLips[8]）
   └→ 嘴左角 ≈ outerLips[12]
   └→ 嘴右角 ≈ outerLips[4]

2. 计算嘴开合度
   └→ 嘴高度 = abs(上唇中点.y - 下唇中点.y)
   └→ 嘴宽度 = abs(嘴左角.x - 嘴右角.x)
   └→ 归一化比 = 嘴高度 / 嘴宽度（消除距离影响）

3. 状态判定（带滞回区间）
   └→ 归一化比 > mouthOpenThreshold (0.6) → MOUTH_OPEN
   └→ 归一化比 < mouthCloseThreshold (0.4) → MOUTH_CLOSED
   └→ 之间 → 保持上一次状态（滞回）

4. 防抖
   └→ 状态变更后启动 debounceTimer (300ms)
   └→ 防抖期内再次变更 → 重置计时器
   └→ 防抖期满 → 确认状态变更

5. 状态变化事件
   └→ CLOSED → OPEN: 触发 voiceStartRequest
   └→ OPEN → CLOSED: 触发 voiceStopRequest
   └→ 不变: 不触发

6. 输出 MouthStatus
```

### 输出

```swift
enum MouthStatus: String {
    case open    // 张嘴
    case closed  // 闭嘴
    case unknown // 无法判断（人脸不可用）
}

struct MouthEvent {
    let status: MouthStatus
    let ratio: Float       // 归一化嘴开度
    let previousStatus: MouthStatus
    let timestamp: Date
}
```

### 状态机

```
unknown → CLOSED → OPEN → CLOSED → OPEN ...
                ↓防抖期     ↓防抖期
              等待300ms   等待300ms
                ↓          ↓
            (确认关闭)   (确认开启)
                ↓          ↓
           触发stop    触发start
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 嘴部关键点缺失 | status = unknown | `[E07] mouth landmarks unavailable` |
| 说话中快速张嘴闭嘴 | 防抖期内不触发 | `[E07] debounce active, ignoring` |
| 大笑（嘴开太大） | 状态 = OPEN，正常触发 | `[E07] mouth wide open, ratio=0.85` |
| 张嘴但不说话（发呆） | 维持 OPEN，1 分钟后自动关 | `[E07] mouth open idle, auto-closing after 60s` |
| 戴口罩 | 嘴部轮廓不完整 → unknown | `[E07] mask detected, mouth unavailable` |

### 日志模板

```

```

| 测试 | 步骤 | 预期 |
|------|------|------|

| 闭嘴检测 | 闭嘴 | status = closed |

## E08 — 鼠标控制

### 触发条件

### 输入
| 参数 | 类型 | 来源 | 说明 |

## E10 — 语音识别

## E11 — 文字输入

### 触发条件
- E10 输出 VoiceResult (isFinal = true)
- E10 检测到 MouthStatus = closed（嘴闭上触发提交）

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| finalText | String | E10 | 最终识别文字 |
| partialText | String | E10 | 中间结果（实时输入） |

### 处理步骤

```
1. 获取目标元素
   └→ 检查当前激活的 App（NSWorkspace.shared.frontmostApplication）
   └→ 获取当前激活的 UI 元素（AXUIElementCopyAttributeValue）
   └→ 判断是否可编辑：
       ├── 是 textField / textArea / webView 输入框

   └→ 每段 partial 结果 → 
       通过 CGEventPostToPSN 发送到目标应用
       或通过 Accessibility API 设置 selectedText

3. 提交模式（闭嘴后一次性输入）
   └→ 最终的 finalText →
       清除之前的 partial 输入
       重新输入完整 finalText

4. 输入方式选择
   ┌────────────────────────────────────────────────────┐
   │ 方案 A: AXUIElementSetAttributeValue              │
   │   └→ 需要辅助功能权限                              │
   │   └→ 设置 kAXValueAttribute                       │
   │   └→ 优点：直接设置，准确                         │
   │                                                    │
   │ 方案 B: CGEvent 模拟键盘输入                      │
   │   └→ 对每个字符发送 CGEventPostKeyboardEvent      │
   │   └→ 需要辅助功能权限                              │
   │   └→ 优点：兼容所有应用                            │
   │   └→ 缺点：不支持中文输入法（因为模拟的是按键）    │
   │                                                    │
   │ 方案 C: NSPasteboard + Cmd+V                      │
   │   └→ 将文字写入 NSPasteboard.general               │
   │   └→ 发送 cmd+v 粘贴                               │
   │   └→ 优点：支持中文，兼容所有应用                  │
   │   └→ 缺点：会覆盖剪贴板                            │
   │                                                    │
   │ === 推荐方案：C（粘贴） ===                        │
   └────────────────────────────────────────────────────┘
```

### 输出

}

### 状态机

```

     ↓            ↓           ↓
  无结果      无激活App   不可编辑
     ↓            ↓           ↓
   跳过        缓存文字   显示提示
               等待聚焦
```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| 无激活应用 | 缓存文字，等待用户点击 | `[E11] no active app, caching text` |
| 激活的不是输入框 | 缓存文字，等待聚焦到输入框 | `[E11] active element not editable, caching` |
| 粘贴覆盖剪贴板 | 备份原剪贴板内容，输入后恢复 | `[E11] clipboard backup saved` |
| 文字为空 | 跳过 | `[E11] empty text, skipping` |
| 文字过长（> 10KB） | 分段输入 | `[E11] long text, chunking` |
| 中文输入法冲突 | 先关闭中文输入法再粘贴 | `[E11] switching to English input for paste` |
| 目标 App 是 Terminal | 使用 CGEvent 模式（部分 App 不支持粘贴） | `[E11] terminal detected, using CGEvent mode` |

## E12 — 配置管理

### 触发条件
- App 启动时
- 用户打开配置面板
- 用户点击"保存"
- 用户切换配置方案
- 用户在配置面板编辑手势映射

### 输入
| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| userAction | ConfigAction | UI | 加载 / 保存 / 切换 / 新增映射 / 删除映射 |
| mappingData | [GestureAction] | UI | 用户编辑的映射数据 |

### 处理步骤

```
1. 启动时加载
   └→ 检查 config.json 是否存在
       ├── 存在 → 解码 JSON → 覆盖默认
       └── 不存在 → 创建默认配置 → 写入 config.json

2. 响应 UI 操作
   └→ 保存配置:
       先写临时文件 config.tmp.json
       rename → config.json（原子操作）
       通知监听器（DispatchSource.FileSystemObject）
   
   └→ 切换方案:
       当前方案名写入 config.activeProfile
       重新加载配置
       通知监听器
   
   └→ 编辑映射:
       用户在 UI 中选择手势 + 选择动作
       保存到 gestureMapping
   
   └→ 新增映射:
       用户选择"添加新映射"
       弹出手势选择器 + 动作选择器
       GestureAction.gesture = .custom("用户自定义名") 或选择现成手势
       添加到 gestureMapping

3. 配置热加载
   └→ ConfigManager 监听 config.json 文件变化
   └→ 检测到变化 → 重新解码
   └→ 将新配置广播给所有模块（NotificationCenter）
   └→ 模块各自响应（如调整阈值、重新读取映射表）
```

### 输出

```swift
class ConfigManager {
    static let shared = ConfigManager()
    
    var currentConfig: GestureConfig
    var profiles: [String: GestureConfig]
    var activeProfile: String
    
    func load() -> GestureConfig

    func switchProfile(_ name: String)
    func createProfile(_ name: String, basedOn: GestureConfig)
    func deleteProfile(_ name: String)

    func importConfig(from url: URL) throws
    func addMapping(_ action: GestureAction)
    func removeMapping(for gesture: GestureType)
    func updateMapping(for gesture: GestureType, to action: GestureAction)
    func resetToDefaults()
}
```

### 状态机

```

           ├── 存在 → 解码 → 应用
           └── 不存在 → 创建默认配置 → 写入

```

### 错误与边界处理

| 条件 | 行为 | 日志 |
|------|------|------|
| config.json 损坏 | 使用默认配置 + 备份旧文件 | `[E12] config corrupted, using defaults, backup saved as config.bak` |
| 写入失败（磁盘满） | 提示用户 | `[E12] write failed: disk full` |
| 热加载中读取到不完整文件 | 用 rename + 写临时文件避免 | `[E12] atomic write via temp file` |
| 手势映射中有无效 actionType | 跳过无效项 | `[E12] skipping invalid actionType: xxx` |
| 配置版本不兼容 | 自动迁移（版本号字段） | `[E12] config version 1→2, migrating` |
