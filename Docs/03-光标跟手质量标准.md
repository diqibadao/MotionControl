# MotionControl 质量评估标准

> 版本：v4.0 | 日期：2026-06-06 | 基准版本：v0.5.0-silky

## 概述

本文档定义 MotionControl 光标控制的 **23 项量化指标**，覆盖响应性、平滑度、抖动、轨迹、边缘、性能 6 个维度。参考 ISO 9241-9、MacKenzie 轨迹模型、US Patent 可变绝对映射、Meta UmeTrack。

**铁律：任何改动不得使任何指标恶化。只能变好，不能变差。**

每次修改算法后，运行 `scripts/analyze-cursor-log.sh` 输出全部 23 项指标并与基准对比。

## 目标校准说明

v4.0 目标基于 v0.5.0-silky 实测值设定，原则：
- 已达到的：目标设在当前值附近（保持不下滑）
- 未达到的：目标设在可实现的改善幅度（基于行业参考）
- 待实现的：标注"待实现"，排入后续版本

**所有目标必须 ≥ 基准值，绝不允许回退。**

## 使用方式

```bash
# 1. 测试
./.build/debug/MotionControl > /tmp/motioncontrol-test.log 2>&1 &

# 2. 一键分析全部23项指标
./scripts/analyze-cursor-log.sh /tmp/motioncontrol-test.log

# 3. 与基准对比，23项全部不得恶化
```
