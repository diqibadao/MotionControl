# 光标加速算法重构 — 实施计划

> **测试规格说明书**：详见事件链文档 `.hermes/plans/2026-05-31-cursor-acceleration-events.md`
> **来源**：行业鼠标加速算法调研（macOS/Windows/libinput）

**Goal:** 将 `updateWithDelta` 的固定 factor 三段式替换为速度基的加速曲线，解决光标移动不够远、不够平滑的问题。

**架构分层标记：**

| 层 | 模块 | 不动/改 | 说明 |
|----|------|---------|------|
| **采集层** | CameraService, DetectionPipeline, HandPoseDetector | 不动 | 只产出原始 Vision 坐标 |
| **策略层** | CursorController.updateWithDelta | **改** | factor 三段式 → 速度基加速曲线 |
| **执行层** | MouseController, CursorController.computeCursor | 不动 | 只负责系统光标操作 |

**改动类型：** P-LOGIC

### Task 1: 重构 updateWithDelta 加速算法

**Objective:** 将固定 factor 替换为 libinput 风格的 velocity-based acceleration curve。

**Files:**
- Modify: `Sources/MotionControl/Control/CursorController.swift` — updateWithDelta 方法

**改动说明：**

当前代码：
```swift
func updateWithDelta(tip: CGPoint, lastTip: CGPoint, screenSize: CGSize, sensitivity: Float) {
    let dx = (lastTip.x - tip.x) * screenSize.width * CGFloat(sensitivity)
    let dy = (tip.y - lastTip.y) * screenSize.height * CGFloat(sensitivity)
    
    guard abs(dx) > 5 || abs(dy) > 5 else { return }
    
    let dist = sqrt(dx*dx + dy*dy)
    let factor: CGFloat = dist < 30 ? 1 : (dist < 200 ? 3 : 6)
    currentPosition.x += dx / factor
    currentPosition.y += dy / factor
    
    currentPosition.x = max(0, min(currentPosition.x, screenSize.width))
    currentPosition.y = max(0, min(currentPosition.y, screenSize.height))
    fingerActive = true
}
```

改为：
```swift
func updateWithDelta(tip: CGPoint, lastTip: CGPoint, screenSize: CGSize, sensitivity: Float, dt: TimeInterval = 1.0/15.0) {
    let dx = (lastTip.x - tip.x) * screenSize.width * CGFloat(sensitivity)
    let dy = (tip.y - lastTip.y) * screenSize.height * CGFloat(sensitivity)
    
    // 极低死区：仅过滤亚像素 jitter（比原来 5px 更小）
    guard abs(dx) > 2 || abs(dy) > 2 else { return }
    
    // 速度 = 位移 / 时间
    let velocity = sqrt(dx*dx + dy*dy) / CGFloat(max(dt, 0.001))
    
    // 加速度因子：libinput adaptive 模型
    // 慢速→精细（×0.4），中速→1:1，快速→加速（最高 ×4）
    let factor: CGFloat
    if velocity < 50 {
        factor = 0.4  // 慢速，精细控制（÷0.4 = ×2.5屏幕位移）
    } else if velocity < 200 {
        factor = 1.0  // 中速，1:1
    } else {
        factor = min(1.0 + (velocity - 200) / 800.0 * 3.0, 4.0)  // 快速，加速最多4x
    }
    
    currentPosition.x += dx * factor  // 注意：乘 factor，不再除
    currentPosition.y += dy * factor
    
    currentPosition.x = max(0, min(currentPosition.x, screenSize.width))
    currentPosition.y = max(0, min(currentPosition.y, screenSize.height))
    
    fingerActive = true
}
```

**关键变化：**
1. factor 现在是乘（增益）不是除（衰减）
2. 基于 velocity（速度）判断，不是基于 dist（位移）
3. 慢速→增益 0.4x（精细），快速→增益最高 4x（跨屏）
4. 死区从 5px 降到 2px（过滤极端 jitter 但不丢小位移）
5. 新增 `dt` 参数（帧间时间），使速度计算与帧率无关

### Task 3: 新增 Velocity EMA 平滑（去抖动）

**Objective:** 在 `CursorController` 中增加 velocity EMA 平滑，过滤 Vision 检测 jitter。

**Files:**
- Modify: `Sources/MotionControl/Control/CursorController.swift`

**改动说明：**

在 `CursorController` 类中添加两个属性：
```swift
/// Velocity EMA 平滑
private var smoothVx: CGFloat = 0
private var smoothVy: CGFloat = 0
private let velocityEMAAlpha: CGFloat = 0.3
```

在 `updateWithDelta` 方法开头、计算 raw delta 之后、乘以 factor 之前，插入 velocity EMA：

```swift
func updateWithDelta(tip: CGPoint, lastTip: CGPoint, screenSize: CGSize, sensitivity: Float, dt: TimeInterval = 1.0/15.0) {
    let dx = (lastTip.x - tip.x) * screenSize.width * CGFloat(sensitivity)
    let dy = (tip.y - lastTip.y) * screenSize.height * CGFloat(sensitivity)
    
    guard abs(dx) > 2 || abs(dy) > 2 else { return }
    
    // Velocity EMA 平滑（对速度做平滑，不对位置做平滑）
    // 保留用户的意图移动，过滤单帧 jitter 噪声
    let rawVx = dx / CGFloat(max(dt, 0.001))
    let rawVy = dy / CGFloat(max(dt, 0.001))
    smoothVx = velocityEMAAlpha * rawVx + (1 - velocityEMAAlpha) * smoothVx
    smoothVy = velocityEMAAlpha * rawVy + (1 - velocityEMAAlpha) * smoothVy
    
    // 用平滑后的速度重新算 delta
    let smoothDx = smoothVx * CGFloat(max(dt, 0.001))
    let smoothDy = smoothVy * CGFloat(max(dt, 0.001))
    
    let velocity = sqrt(smoothDx*smoothDx + smoothDy*smoothDy) / CGFloat(max(dt, 0.001))
    
    let factor: CGFloat
    if velocity < 50 {
        factor = 0.4
    } else if velocity < 200 {
        factor = 1.0
    } else {
        factor = min(1.0 + (velocity - 200) / 800.0 * 3.0, 4.0)
    }
    
    currentPosition.x += smoothDx * factor
    currentPosition.y += smoothDy * factor
    
    currentPosition.x = max(0, min(currentPosition.x, screenSize.width))
    currentPosition.y = max(0, min(currentPosition.y, screenSize.height))
    
    fingerActive = true
}
```
