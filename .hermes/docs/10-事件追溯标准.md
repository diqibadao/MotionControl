# 事件级别可回溯可重现标准（Universal Event Traceability Standard）

> 适用于所有项目、所有功能、所有代码。

---

## 核心原则

**每一行重要的代码，都要能回答三个问题：**
1. **输入是什么？** — 参数值、数据来源
2. **处理过程是什么？** — 经过什么计算、什么阈值
3. **输出是什么？** — 结果值、副作用

---

## 标准日志格式

```
[yyyy-MM-dd HH:mm:ss] [event_name] IN: key=val, key=val → OUT: key=val, key=val (duration_ms)
```

### 字段规则

| 字段 | 必填 | 说明 |
|------|------|------|
| 时间戳 | ✅ | `DateFormatter("yyyy-MM-dd HH:mm:ss")` |
| 事件名 | ✅ | 小写+下划线，如 `hand_detect`、`gesture_analyze` |
| IN | ✅ | 输入参数摘要（关键字段+值） |
| OUT | ✅ | 输出结果摘要（关键字段+值） |
| 耗时 | 推荐 | 处理耗时（毫秒） |

### 事件命名规范

```
{模块}_{动作}
示例：
  hand_detect        — 手部检测
  gesture_analyze    — 手势分析
  gaze_estimate      — 注视估计
  mouth_detect       — 嘴型检测
  mouse_leftClick    — 鼠标左键点击
  text_inject        — 文字输入
  voice_start        — 语音开始
  voice_result       — 语音识别结果
```

## 实施规则

### 规则 1：每个处理函数必须有日志

```swift
// ✅ 正确：有日志可追溯
func detect(in pixelBuffer: CVPixelBuffer) -> HandPoseResult? {
    let start = Date()
    // ...检测逻辑...
    EventLogger.log(event: "hand_detect",
                    input: "buffer=\(pixelBuffer.width)x\(pixelBuffer.height)",
                    output: "detected=\(result != nil) landmarks=\(count) conf=\(conf)",
                    duration: Date().timeIntervalSince(start))
    return result
}

// ❌ 错误：无日志不可追溯
func detect(in pixelBuffer: CVPixelBuffer) -> HandPoseResult? {
    // ...检测逻辑...
    return result
}
```

### 规则 2：输入输出要有足够信息重现

```
IN: detected=true, landmarks=21, conf=0.91
OUT: gesture=GRAB, confidence=0.87, isRepeat=false

✅ 可以重放：知道置信度 0.91、手势 GRAB
❌ 不够：IN: ok, OUT: done（毫无信息量）
```

### 规则 3：不使用日志来记录配置/常量

不需要日志的：
- 配置加载（一次性的，启动时做一次）
- 常量定义
- 纯 getter/setter

### 规则 4：链路追踪

跨模块调用需要能串联：

```
[hand_detect]       → OUT: result=HandPoseResult(id=A1)
[gesture_analyze]   → IN: hand_id=A1 → OUT: gesture=GRAB
[mouse_leftClick]   → IN: gesture=GRAB → OUT: click at (960,540)
```

可以用 `frame_id` 或 `request_id` 串联：

```
[hand_detect]       [frame:1247] → ...
[gesture_analyze]   [frame:1247] → ...
[mouse_leftClick]   [frame:1247] → ...
```

### 规则 5：禁止日志敏感信息

❌ 不记录：密码、API Key、Token、完整文件路径
✅ 记录：输入尺寸、检测置信度、动作类型、耗时

---

## 审计清单（Gate 5 必查）

```
□ 每个处理函数都有 EventLogger 日志
□ 日志包含 IN/OUT 关键字段
□ 日志包含处理耗时
□ 日产能串联（frame_id / request_id）
□ 无敏感信息泄露
□ 日志信息量足够可重现
```

## EventLogger 模板（各项目通用）

```swift
import Foundation

class EventLogger {
    private static let df: DateFormatter = {
        let f = DateFormatter()
        f.dateFormat = "yyyy-MM-dd HH:mm:ss"
        return f
    }()
    
    static func log(event: String, 
                    frame: Int? = nil, 
                    input: String, 
                    output: String, 
                    durationMs: Double? = nil) {
        let timestamp = df.string(from: Date())
        var log = "[\(timestamp)] [\(event)]"
        if let f = frame { log += " [frame:\(f)]" }
        log += " IN: \(input) → OUT: \(output)"
        if let d = durationMs { log += " (\(Int(d))ms)" }
        print(log)
    }
}
```

## 与其他规范的关系

| 规范 | 关系 |
|------|------|
| 六道门禁 Gate 5 (审查) | 审计清单加入审核项 |
| 完整数据链记录 | 日志是数据链的实时版本，数据链是日志的持久化版本 |
| SOUL.md 调研铁律 | 调研阶段日志帮助验证假设 |
