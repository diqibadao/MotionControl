## P2+P3 — 食指方向 → 速度映射（核心重构）

### 原理

从**绝对定位**改为**方向性控制（Joystick 模式）**。

计算食指方向向量作为光标速度：

```swift
// 食指方向（使用 PIP 比 MCP 更稳定）
let dx = indexTip.x - indexPIP.x
let dy = indexPIP.y - indexTip.y  // Vision y 向上
let length = sqrt(dx*dx + dy*dy)

// 死区 + 二次方曲线
guard length > deadZone else { stop() }
let speed = pow((length - deadZone)/(maxExt - deadZone), 2.0)
```

### 滤波：One Euro Filter

比指数平滑更优的自适应低通滤波器：

```swift
// 自适应截止频率
let cutoff = minCutoff + beta * abs(velocity)
let alpha = 1.0 / (1.0 + dt * cutoff)
filtered = alpha * filtered + (1.0 - alpha) * raw
```

| 行为 | 效果 |
|------|------|
| 手指微动/静止（速度≈0） | 截止频率低 → 强滤波去抖 |
| 手指快速移动 | 截止频率高 → 低延迟跟随 |

### 手指伸展检测（五指识别）

```swift
let ext = hand.fingerExtension()
let indexOK = ext[.index]  > indexThreshold     // 食指伸出
let othersOK = ext[.middle] < middleThreshold   // 其他卷曲
            && ext[.ring]   < ringThreshold
            && ext[.little] < littleThreshold
let allOpen = ext.values.allSatisfy { $0 > openThreshold }  // 五指全伸=离合器
```

### 光标合成

```swift
// 指向模式 + 离合器 + One Euro 滤波
if indexOK && othersOK && !allOpen {
    let velocity = computeVelocity(from: direction)
    let smoothVel = oneEuroFilter.filter(velocity)
    cursor.x += smoothVel.x * dt
    cursor.y += smoothVel.y * dt
    cursor = clamp(cursor, to: screen)
}
```

## P4 — 注视追踪修复

### 问题

1. `GazeEstimator` 返回 `pitch=nil`（yaw 也始终为 0）
2. `CursorController.updateGazeOffset` 无条件设 `gazeActive = true`
3. `onGaze` 回调在 `hasFace=false` 时仍调 `updateGazeOffset`

### 修复

**CursorController.swift**：
```swift
func updateGazeOffset(yaw: Float, pitch: Float, hasFace: Bool) {
    yawOffset = yaw
    pitchOffset = pitch
    gazeActive = hasFace  // 只有有人脸时才激活
}
```

**MotionControlApp.swift**：
```swift
detectionPipeline.onGaze = { gazeEstimate in
    state.gazeActive = gazeEstimate.hasFace
    cursorController.updateGazeOffset(
        yaw: gazeEstimate.yawOffset,
        pitch: gazeEstimate.pitchOffset,
        hasFace: gazeEstimate.hasFace  // 传递 hasFace
    )
}
```

**GazeEstimator.swift** — 需检查为什么 `pitch=nil`（可能需配置 Vision 请求支持头部姿态评估）
