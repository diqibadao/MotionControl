# P2+P3 调试：光标不动

## 根因

`updateFingerDirection` 中速度直接用 `dx * sensitivity`（Vision 归一化坐标），
没有乘以屏幕尺寸，导致每秒移动 < 1 像素。

```
rawVx = dx * sensitivity = 0.1 * 1.0 = 0.1
baseCursor.x += rawVx * (1/30) = 0.003 像素/帧
```

## 修复

方案：在 `MotionControlApp.swift` 中调用 `updateFingerDirection` 时，
将 `length` 乘以屏幕宽度（把 Vision 坐标转为像素速度）：

```swift
// 改前
cursorController.updateFingerDirection(direction, length: length,
                                        sensitivity: CGFloat(config.mouseSensitivity))
// 改后
let pixelLength = length * screen.width  // 归一化长度 × 屏幕宽 = 像素速度
cursorController.updateFingerDirection(direction, length: pixelLength,
                                        sensitivity: CGFloat(config.mouseSensitivity))
```

或者直接在 `CursorController.updateFingerDirection` 内部乘以一个大常数。
